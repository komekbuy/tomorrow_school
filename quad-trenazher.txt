Пошаговый прогон вложенных циклов. Жмёшь «Шаг» и видишь одновременно:
    - какая строка кода выполняется прямо сейчас
    - какое условие проверяется и с какими значениями (0 < 3 → да)
    - где стоит курсор в сетке
    - что уже напечаталось

Три режима, настройка размеров, регулятор скорости.
Обязательно погоняй с x=1 и y=1 — там самые частые ошибки.

--------------------------------------------------------------------------------
КАК ПОЛЬЗОВАТЬСЯ
--------------------------------------------------------------------------------

1. Код НЕ копируй — печатай руками. Пальцы запоминают синтаксис,
   глаз замечает то, что при копировании проскакивает.

2. Перед запуском САМ угадай, что выведет программа. Потом сверься.
   Не угадал — разбирайся почему. Вот это и есть учёба.

3. Каждый следующий пример отличается от предыдущего ровно ОДНИМ
   изменением. Смотри, что поменялось и к чему привело.

4. В конце — задачи без примеров. Они показывают, понял ты
   или просто перепечатал.

--------------------------------------------------------------------------------
КОНСПЕКТ
--------------------------------------------------------------------------------

    row = СТРОКА  = высота   (сверху вниз)   → внешний цикл, row < y
    col = КОЛОНКА = ширина   (слева направо) → внутренний цикл, col < x

Почему строки снаружи: экран заполняется построчно, курсор идёт слева
направо и только потом переходит на новую строку. «Вся строка целиком» —
это внутренний цикл, «повторить для каждой строки» — внешний.

    for row := 0; row < y; row++ {
        for col := 0; col < x; col++ {
            fmt.Print("#")      ← выполняется x раз
        }
        fmt.Println()           ← ВНУТРИ внешнего, СНАРУЖИ внутреннего
    }                             = один раз на строку

Внутренний цикл прокручивается ПОЛНОСТЬЮ на каждом шаге внешнего.
Всего печатается y * x символов.

ГДЕ СТАВИТЬ Println — три варианта, три результата:
    после внутреннего цикла   →  строки (правильно)
    внутри внутреннего цикла  →  столбик по одному символу
    снаружи обоих циклов      →  одна длинная строка

if / else = ВЫБОР ОДНОГО ИЗ ДВУХ. Выполнится ровно одна ветка.
Что оставил СНАРУЖИ скобок — выполнится всегда.

ДВА СТИЛЯ НУМЕРАЦИИ — оба рабочие, не смешивать в одном файле:
    for row := 0; row < y;  row++    крайние: row == 0  и  row == y-1
    for row := 1; row <= y; row++    крайние: row == 1  и  row == y

================================================================================
                    ГРАБЛИ (реальные, из нашего проекта)
================================================================================

1. ОДИНАРНЫЕ КАВЫЧКИ С fmt.Print → ПЕЧАТАЮТСЯ ЧИСЛА

       fmt.Print('A')     → выводит 65    (руна это число!)
       fmt.Print("A")     → выводит A

   С fmt нужны ДВОЙНЫЕ кавычки.
   С z01.PrintRune наоборот — ОДИНАРНЫЕ, она принимает руну.

       fmt.Print       →  "двойные"     (string)
       z01.PrintRune   →  'одинарные'   (rune)

2. ЗАБЫТЫЙ else → ПРОПАДАЕТ ЦЕЛАЯ ЧАСТЬ ФИГУРЫ

   Было:
       if row == 0 || row == y-1 {
           ...верх и низ...
       }                              ← нет else!

   Результат: средние строки не печатались вообще, выходило
       o---o
                ← пустая строка
       o---o

3. ЗАБЫТЫЙ else, ВАРИАНТ 2 → ЛИШНИЙ СИМВОЛ

   Было:
       if col == 0 {
           fmt.Print("o")
       }
       fmt.Print("-")     ← СНАРУЖИ условия, печатается ВСЕГДА

   Результат: o----- вместо o---o
   Правило: если выбираешь одно из двух — оба варианта
   должны быть внутри if и else.

4. ДУБЛИРОВАНИЕ УСЛОВИЯ ВНУТРИ else

       if col == 0 || col == x-1 {
           fmt.Print("o")
       } else {
           if col == 0 || col == x-1 {   ← ТО ЖЕ САМОЕ
               fmt.Print("-")
           } else {
               fmt.Print(" ")
           }
       }

   Внутри else это условие ГАРАНТИРОВАННО ложно — иначе бы
   мы туда не попали. Дефис не напечатается никогда.

5. x < 0 ВМЕСТО x <= 0

   Ноль не является положительным числом. При x = 0 функция
   с проверкой  x < 0  всё равно пойдёт рисовать.

6. ДВА ОТДЕЛЬНЫХ if ВМЕСТО if/else

       if col == 0     { fmt.Print("L") }
       if col == x-1   { fmt.Print("R") }

   При x = 1 позиция col=0 является И первой, И последней —
   сработают ОБА, напечатается два символа вместо одного.
   С if/else такого не будет.

7. ОШИБКА НА ЕДИНИЦУ

       for col := 0; col < x-1   ← потеряется последний символ
       for col := 0; col < x     ← правильно

   Проверяй: посмотри на ПОСЛЕДНИЙ элемент и спроси себя,
   должен ли он попасть в вывод.

8. ГОЛЫЕ КОММЕНТАРИИ ИЗ ЧУЖОГО КОДА

   В наших файлах висели комментарии "// Properly escaped backslash"
   там, где никаких слешей нет — остались от копирования.
   На защите спросят, что это значит. Убирайте чужое.
