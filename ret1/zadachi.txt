ЗАДАЧА 3.  IsEven(n int) bool
--------------------------------------------------------------------------------
Возвращает true, если число чётное.
Проверить на 4, 7 и 0.

Ожидается:
true
false
true

ПОДСКАЗКА: чётное = остаток от деления на 2 равен нулю.
           %   вычислить остаток      7 % 2  даёт 1
           %=  остаток + присвоить    n %= 2  это n = n % 2
           ==  сравнить               n == 0  даёт правду или ложь

СТАТУС: ✅ решено, коротким вариантом:  return n % 2 == 0
        (без if — сравнение само по себе уже bool)
ГРАБЛИ: сначала написал  if n %= 0  — перепутал оператор присваивания
        с остатком (%=) и сравнение (==). И печатал вместо return,
        хотя тип возврата был объявлен как bool.

ЗАДАЧА 4.  Max(a int, b int) int
--------------------------------------------------------------------------------
Возвращает большее из двух чисел.
Проверить: Max(3, 9), Max(10, 2), Max(5, 5)

Ожидается:
9
10
5

СТАТУС: ✅ решено, вариантом с ранним выходом (без else):

        func Max(a, b int) int {
            if a > b {
                return a
            }
            return b
        }

        Работает потому, что return прерывает функцию: дошли до последней
        строки — значит первое условие не сработало.
        Краевой случай Max(5, 5) проверен, даёт 5.

ЗАДАЧА 5.  CountTo(n int) int
--------------------------------------------------------------------------------
Возвращает сумму всех чисел от 1 до n.
Например для 5:  1+2+3+4+5 = 15
Проверить на 5 и 10.

Ожидается:
15
55

ПОДСКАЗКА: нужен цикл и переменная-накопитель.
           Создать переменную = 0 ДО цикла,
           внутри цикла прибавлять к ней текущее число,
           после цикла вернуть её.
           Похоже на счётчик, только считает не повторы, а сумму.

СТАТУС: ✅ решено 03.08.2026, самостоятельно (с наводками, без готового кода)

        func CountTo(n int) int {
            x := 0
            for i := 1; i <= n; i++ {
                x = x + i
            }
            return x
        }

ГРАБЛИ (пять попыток, каждая — отдельная ошибка):

  1) цикл шёл до x вместо n — параметр n не использовался вообще
  2) x++ в третьей части for вместо i++ -> i не менялся -> БЕСКОНЕЧНЫЙ цикл
  3) return x + i внутри цикла — вычислял верно, но выходил на первом шаге
  4) return x == x + i — сравнение вместо присваивания
     ошибка: cannot use x == x + i (untyped bool value) as int value
  5) return x = x + i — присваивание после return
     ошибка: expected '==', found '='
     ПРИЧИНА: return требует ЗНАЧЕНИЕ, а присваивание — это ДЕЙСТВИЕ.
              В одну строку не совмещаются.
  6) границы i := 0; i < n — дало 10 вместо 15 (терялось последнее число)

ТРИ ЗНАКА — ГЛАВНАЯ ПУТАНИЦА ЭТОЙ ЗАДАЧИ:

    :=   создаёт переменную и кладёт значение     x := 0
    =    кладёт в уже созданную                   x = x + i
    ==   спрашивает «равны ли», даёт true/false   x == 7

КОНТРОЛЬНЫЕ ВОПРОСЫ (задавались 03.08, 2 из 3 верно):

  1) CountTo(0) и CountTo(-3) -> 0. ✅ ответил верно:
     цикл не делает ни шага, возвращается x, который остался нулём.

  2) что будет, если перенести x := 0 ВНУТРЬ цикла? ❌ ответил «ничего»
     ПРОВЕРЕНО ЭКСПЕРИМЕНТОМ — вернёт 0, накопления не будет:
     := внутри цикла создаёт НОВУЮ переменную на каждом шаге,
     она живёт один шаг и умирает. Внешний x никто не трогает.
     ПРАВИЛО: накопитель обязан жить дольше цикла -> создаётся СНАРУЖИ,
              внутри его можно только менять через =

  3) почему return x стоит после цикла? ✅ ответил верно по смыслу.
     Поправка формулировки: return срабатывает НЕ «если сходится условие»,
     а безусловно, как только до него дошло управление.
