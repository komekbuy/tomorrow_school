SETUP
==============================================================================

Create the topic folder and module — type it, don't copy:

    mkdir str1
    cd str1
    go mod init str1

From here on, type all code into main.go in that folder.
To run the program:

    go run .

------------------------------------------------------------------------------
HOW TO WORK WITH THE EXAMPLES
------------------------------------------------------------------------------

1. Type it out. Don't copy-paste — while you type, your eye catches the
   brackets, dots and quotes that copying slides right past.

2. BEFORE running, write down what it will print. Then run it and compare
   with the answer under the example.

3. A mismatch is the valuable part. Work out why it came out that way
   before moving on.

4. Once it works, break it on purpose: drop the quotes, change the type,
   use a different index. Read what the compiler says.

5. Each example differs from the previous one by a single change — it is
   named in the heading. Spot it before you run anything.

------------------------------------------------------------------------------
EXAMPLE 1.  What changed: the first one, type it all
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Go"
	fmt.Println(s)
	fmt.Println(len(s))
}

OUTPUT:
Go
2

Two Latin letters, two bytes. For now len matches the letter count — that coincidence is about to end.
Break it: set s := "Go!" and predict what len prints.

------------------------------------------------------------------------------
EXAMPLE 2.  What changed: added printing the first element
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Go"
	fmt.Println(s)
	fmt.Println(len(s))
	fmt.Println(s[0])
}

OUTPUT:
Go
2
71

You expected a letter and got a number. s[0] pulls a byte, and 71 is the code of “G”.

------------------------------------------------------------------------------
EXAMPLE 3.  What changed: wrapped <code>s[0]</code> in <code>string</code>
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Go"
	fmt.Println(s)
	fmt.Println(len(s))
	fmt.Println(string(s[0]))
}

OUTPUT:
Go
2
G

string says “show this number as a character”. The value is the same, only the type changed.

------------------------------------------------------------------------------
EXAMPLE 4.  What changed: the string became Cyrillic
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Дом"
	fmt.Println(s)
	fmt.Println(len(s))
	fmt.Println(string(s[0]))
}

OUTPUT:
Дом
6
Ð

Three letters, but len says six. And instead of “Д” you get “Ð” — s[0] pulled only the first half of the letter, and string honestly showed the character with that code. This is the central trap of the topic.

------------------------------------------------------------------------------
EXAMPLE 5.  What changed: printing all the bytes instead of one
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Дом"
	fmt.Println(s)
	fmt.Println(len(s))
	fmt.Println([]byte(s))
}

OUTPUT:
Дом
6
[208 148 208 190 208 188]

Here is the whole string from inside: six numbers for three letters, two per letter. There are no letters in memory.
Break it: set s := "Go" and compare — you'll see two numbers.

------------------------------------------------------------------------------
EXAMPLE 6.  What changed: a <code>range</code> loop instead of printing bytes
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Дом"
	fmt.Println(s)
	fmt.Println(len(s))
	for i, c := range s {
		fmt.Println(i, string(c))
	}
}

OUTPUT:
Дом
6
0 Д
2 о
4 м

The letters are whole at last. But the offsets go 0, 2, 4 — i counts bytes, not steps. There were three steps.

------------------------------------------------------------------------------
EXAMPLE 7.  What changed: <code>range</code> walks <code>[]rune(s)</code>, not the string
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Дом"
	fmt.Println(s)
	fmt.Println(len(s))
	for i, c := range []rune(s) {
		fmt.Println(i, string(c))
	}
}

OUTPUT:
Дом
6
0 Д
1 о
2 м

One change and the offsets became 0, 1, 2. Over a rune slice range behaves like over an ordinary list: the index is the character number. Use this when you actually need the letter's position.

------------------------------------------------------------------------------
EXAMPLE 8.  What changed: editing a rune and rebuilding the string
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Дом"
	r := []rune(s)
	r[0] = 'Т'
	fmt.Println(s)
	fmt.Println(string(r))
}

OUTPUT:
Дом
Том

The original didn't change — you edited a rune copy. Break it: write s[0] = 'Т' directly and read the error.

------------------------------------------------------------------------------
EXAMPLE 9.  What changed: an accumulator building a new string instead of editing
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Дом"
	res := ""
	for _, c := range s {
		res = string(c) + res
	}
	fmt.Println(s)
	fmt.Println(res)
}

OUTPUT:
Дом
моД

Each new character is glued on the left, so the string grows backwards.
Break it: change it to res = res + string(c) and see what comes out.

------------------------------------------------------------------------------
EXAMPLE 10.  What changed: added a slice and a string comparison
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Дом"
	res := ""
	for _, c := range s {
		res = string(c) + res
	}
	fmt.Println(res)
	fmt.Println(s[2:], s[:2])
	fmt.Println(s == "Дом", s < "Кот")
}

OUTPUT:
моД
ом Д
true true

s[2:] gives “ом” because the letter “Д” took bytes 0 and 1. s < "Кот" is true: comparison goes by codes and “Д” comes before “К”.
Break it: write s[1:] and look at the broken stub.
