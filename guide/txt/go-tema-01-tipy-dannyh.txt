ПОДГОТОВКА
==============================================================================

Создай папку темы и модуль — набери руками, не копируй:

    mkdir type1
    cd type1
    go mod init type1

Дальше весь код набирай в файл main.go в этой папке.
Запуск программы:

    go run .

------------------------------------------------------------------------------
КАК РАБОТАТЬ С ПРИМЕРАМИ
------------------------------------------------------------------------------

1. Набирай руками. Не копируй мышкой — пока печатаешь, глаз замечает
   скобки, точки и кавычки, которые при копировании проходят мимо.

2. ПЕРЕД запуском запиши, что программа выведет. Потом запусти и сверь
   с ответом под примером.

3. Не совпало — это и есть самое ценное место. Разберись, почему вышло
   именно так, и только потом иди дальше.

4. Заработало — сломай нарочно: убери кавычки, поменяй тип, поставь другой
   индекс. Прочитай, что скажет компилятор.

5. Каждый следующий пример отличается от предыдущего одним изменением —
   оно указано в заголовке. Найди его глазами до запуска.

------------------------------------------------------------------------------
ПРИМЕР 1.  Изменилось: первый, набирай целиком
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	x := 42
	fmt.Println(x)
	fmt.Printf("%T\n", x)
}

ВЫВОД:
42
int

%T показывает тип. Это самый быстрый способ проверить, что на самом деле лежит в переменной.
Сломай: добавь строку y := 5 и не используй её. Программа не соберётся — Go не разрешает создавать переменную впустую.

------------------------------------------------------------------------------
ПРИМЕР 2.  Изменилось: у числа появилась точка
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	x := 42.0
	fmt.Println(x)
	fmt.Printf("%T\n", x)
}

ВЫВОД:
42
float64

Ловушка: на экране «42» без нуля, выглядит как в первом примере — а тип уже другой. Судить о типе по тому, что видно, нельзя.

------------------------------------------------------------------------------
ПРИМЕР 3.  Изменилось: появились двойные кавычки
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	x := "42"
	fmt.Println(x)
	fmt.Printf("%T\n", x)
}

ВЫВОД:
42
string

На экране снова то же самое, а считать с этим уже нельзя. Сломай: попробуй x + 1.

------------------------------------------------------------------------------
ПРИМЕР 4.  Изменилось: кавычки стали одинарными
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	x := '4'
	fmt.Println(x)
	fmt.Println(string(x))
	fmt.Printf("%T\n", x)
}

ВЫВОД:
52
4
int32

52 — это код символа «4». rune и int32 — одно и то же имя для одного типа.

------------------------------------------------------------------------------
ПРИМЕР 5.  Изменилось: символ минус символ
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	fmt.Println('7' - '0')
	fmt.Println(string(rune('0' + 7)))
}

ВЫВОД:
7
7

Первая семёрка — число, вторая — символ. На экране одинаковые, по сути разные. Первая строка переводит символ в цифру, вторая — обратно.

------------------------------------------------------------------------------
ПРИМЕР 6.  Изменилось: целое деление и остаток
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	a := 7
	b := 2
	fmt.Println(a / b)
	fmt.Println(a % b)
	fmt.Println(float64(a) / float64(b))
}

ВЫВОД:
3
1
3.5

Сломай: убери float64 у одного из двух чисел в последней строке и прочитай ошибку.

------------------------------------------------------------------------------
ПРИМЕР 7.  Изменилось: длина строки: латиница и кириллица
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	fmt.Println(len("Hello"), len("Привет"))
	fmt.Println("Hi"[0])
	fmt.Println(string("Hi"[0]))
}

ВЫВОД:
5 12
72
H

12, а не 6 — len считает байты. 72 — код символа «H».

------------------------------------------------------------------------------
ПРИМЕР 8.  Изменилось: цикл по строке — следи за номерами
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Привет"
	count := 0
	for i, c := range s {
		fmt.Println(i, string(c))
		count++
	}
	fmt.Println("букв:", count, "байтов:", len(s))
}

ВЫВОД:
0 П
2 р
4 и
6 в
8 е
10 т
букв: 6 байтов: 12

Номер прыгает через два — единицу «съела» предыдущая буква. Шагов шесть, а len двенадцать: это разные числа.

------------------------------------------------------------------------------
ПРИМЕР 9.  Изменилось: строку менять нельзя — но можно собрать новую
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "hello"
	r := []rune(s)
	r[0] = 'H'
	fmt.Println(s)
	fmt.Println(string(r))
}

ВЫВОД:
hello
Hello

Исходная строка не изменилась — правили копию, разложенную на руны. Сломай: попробуй s[0] = 'H' напрямую.

------------------------------------------------------------------------------
ПРИМЕР 10.  Изменилось: массив, слайс и нулевые значения
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	arr := [3]int{1, 2, 3}
	sl := []int{1, 2, 3}

	sl = append(sl, 4)
	arr[0] = 99

	fmt.Println(arr, len(arr))
	fmt.Println(sl, len(sl))

	var n int
	var s string
	var b bool
	var empty []int
	fmt.Println(n, s == "", b, empty == nil, len(empty))
}

ВЫВОД:
[99 2 3] 3
[1 2 3 4] 4
0 true false true 0

Сломай обязательно: добавь строку arr = append(arr, 4) и прочитай текст ошибки — он и есть ответ на вопрос, чем массив отличается от слайса.

------------------------------------------------------------------------------
ПРИМЕР 11.  Изменилось: в одной строке печати несколько дырок
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	x := 42
	s := "Go"

	fmt.Printf("%v %T\n", x, x)
	fmt.Printf("%v %q\n", s, s)
	fmt.Printf("%v %v\n", len(s), len(s) == 0)
}

ВЫВОД:
42 int
Go "Go"
2 false

Дырок в строке столько же, сколько аргументов после неё, и разбираются они по порядку. %v печатает любое значение, %q — строку в кавычках, поэтому во второй строке Go и "Go" выглядят по-разному. В третьей строке аргументы вообще не переменные, а выражения — считаются на месте. Сломай: убери один аргумент и прочитай, что скажет программа.
