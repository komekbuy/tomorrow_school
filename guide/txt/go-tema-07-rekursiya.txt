ПОДГОТОВКА
==============================================================================

Создай папку темы и модуль — набери руками, не копируй:

    mkdir rec1
    cd rec1
    go mod init rec1

Дальше весь код набирай в файл main.go в этой папке.
Запуск программы:

    go run .

------------------------------------------------------------------------------
КАК РАБОТАТЬ С ПРИМЕРАМИ
------------------------------------------------------------------------------

1. Набирай руками. Не копируй мышкой — пока печатаешь, глаз замечает
   скобки, точки и кавычки, которые при копировании проходят мимо.

2. ПЕРЕД запуском запиши, что программа выведет. Потом запусти и сверь
   с ответом под примером.

3. Не совпало — это и есть самое ценное место. Разберись, почему вышло
   именно так, и только потом иди дальше.

4. Заработало — сломай нарочно: убери кавычки, поменяй тип, поставь другой
   индекс. Прочитай, что скажет компилятор.

5. Каждый следующий пример отличается от предыдущего одним изменением —
   оно указано в заголовке. Найди его глазами до запуска.

------------------------------------------------------------------------------
ПРИМЕР 1.  Изменилось: первый, набирай целиком
------------------------------------------------------------------------------
package main

import "fmt"

func down(n int) {
	if n == 0 {
		return
	}
	fmt.Println(n)
	down(n - 1)
}

func main() {
	down(3)
}

ВЫВОД:
3
2
1

Печать стоит до вызова себя, поэтому числа выходят на спуске — в том порядке, в каком функция уходит вглубь. Ноль не печатается: на нём срабатывает остановка.
Сломай: убери if n == 0 { return } и запусти. Через долю секунды получишь fatal error: stack overflow — так выглядит рекурсия без остановки.

------------------------------------------------------------------------------
ПРИМЕР 2.  Изменилось: печать переехала под вызов
------------------------------------------------------------------------------
package main

import "fmt"

func down(n int) {
	if n == 0 {
		return
	}
	down(n - 1)
	fmt.Println(n)
}

func main() {
	down(3)
}

ВЫВОД:
1
2
3

Переставили две строки — вывод перевернулся. Пока идёт спуск, не печатается ничего; когда самый глубокий вызов закончился, каждый печатает своё n по дороге назад.

------------------------------------------------------------------------------
ПРИМЕР 3.  Изменилось: печатаем и до вызова, и после
------------------------------------------------------------------------------
package main

import "fmt"

func down(n int) {
	if n == 0 {
		return
	}
	fmt.Println(">", n)
	down(n - 1)
	fmt.Println("<", n)
}

func main() {
	down(3)
}

ВЫВОД:
> 3
> 2
> 1
< 1
< 2
< 3

Сверху спуск, снизу подъём, и они зеркальны. Строку < 3 печатает тот самый первый вызов, который всё это время ждал: его n никуда не делось.

------------------------------------------------------------------------------
ПРИМЕР 4.  Изменилось: функция стала возвращать число
------------------------------------------------------------------------------
package main

import "fmt"

func sum(n int) int {
	if n == 0 {
		return 0
	}
	return n + sum(n-1)
}

func main() {
	fmt.Println(sum(4))
}

ВЫВОД:
10

Вместо печати — возврат. Сложение n + sum(n-1) не может выполниться, пока вложенный вызов не вернёт своё число, поэтому вся арифметика идёт на подъёме.
Сломай: замени return 0 на return 1 — ответ станет 11. Дно даёт лишнюю единицу, и она попадает в сумму.

------------------------------------------------------------------------------
ПРИМЕР 5.  Изменилось: внутрь добавлена печать результата
------------------------------------------------------------------------------
package main

import "fmt"

func sum(n int) int {
	if n == 0 {
		return 0
	}
	r := n + sum(n-1)
	fmt.Printf("sum(%d) = %d\n", n, r)
	return r
}

func main() {
	fmt.Println(sum(4))
}

ВЫВОД:
sum(1) = 1
sum(2) = 3
sum(3) = 6
sum(4) = 10
10

Строки идут снизу вверх: первым напечатался sum(1), последним sum(4). Числа собираются на подъёме, от дна к самому первому вызову. Это и есть способ увидеть, что делает непонятная рекурсия.

------------------------------------------------------------------------------
ПРИМЕР 6.  Изменилось: плюс стал умножением, а ноль в базе — единицей
------------------------------------------------------------------------------
package main

import "fmt"

func fact(n int) int {
	if n == 0 {
		return 1
	}
	r := n * fact(n-1)
	fmt.Printf("fact(%d) = %d\n", n, r)
	return r
}

func main() {
	fmt.Println(fact(5))
}

ВЫВОД:
fact(1) = 1
fact(2) = 2
fact(3) = 6
fact(4) = 24
fact(5) = 120
120

Два маленьких изменения — и та же форма считает факториал.
Сломай: верни в базу return 0. Ответ станет нулём: на подъёме всё умножается на этот ноль. Значение дна — часть ответа.

------------------------------------------------------------------------------
ПРИМЕР 7.  Изменилось: шаг к остановке — деление, а не вычитание
------------------------------------------------------------------------------
package main

import "fmt"

func digits(n int) int {
	if n == 0 {
		return 0
	}
	r := n%10 + digits(n/10)
	fmt.Printf("digits(%d) = %d\n", n, r)
	return r
}

func main() {
	fmt.Println(digits(4821))
}

ВЫВОД:
digits(4) = 4
digits(48) = 12
digits(482) = 14
digits(4821) = 15
15

Аргумент приближается к нулю делением: 4821 → 482 → 48 → 4 → 0. Форма прежняя: кусок текущего шага (n%10) плюс вызов себя на остатке.

------------------------------------------------------------------------------
ПРИМЕР 8.  Изменилось: аргумент — строка, а не число
------------------------------------------------------------------------------
package main

import "fmt"

func rev(s string) string {
	if s == "" {
		return ""
	}
	return rev(s[1:]) + s[:1]
}

func main() {
	fmt.Println(rev("hello"))
}

ВЫВОД:
olleh

К остановке приближает укорачивание: s[1:] отрезает первый символ, пустая строка — дно. Первый символ приписывается справа от результата, поэтому строка выходит перевёрнутой.

------------------------------------------------------------------------------
ПРИМЕР 9.  Изменилось: функция вызывает себя дважды в одной строке
------------------------------------------------------------------------------
package main

import "fmt"

func fib(n int) int {
	if n < 2 {
		return n
	}
	return fib(n-1) + fib(n-2)
}

func main() {
	fmt.Println(fib(10))
}

ВЫВОД:
55

Ответ верный, но теперь из каждого вызова растут два. Go считает их по очереди: сначала весь левый fib(n-1) целиком, потом весь правый. Ничего не запоминается, и одни и те же числа считаются заново.

------------------------------------------------------------------------------
ПРИМЕР 10.  Изменилось: добавлен счётчик вызовов
------------------------------------------------------------------------------
package main

import "fmt"

var calls int

func fib(n int) int {
	calls++
	if n < 2 {
		return n
	}
	return fib(n-1) + fib(n-2)
}

func main() {
	fmt.Println(fib(10), calls)
	calls = 0
	fmt.Println(fib(20), calls)
	calls = 0
	fmt.Println(fib(25), calls)
}

ВЫВОД:
55 177
6765 21891
75025 242785

Аргумент вырос в два с половиной раза, а работа — в тысячу. Виновата не рекурсия, а два вызова в строке: одно и то же пересчитывается заново.
Сломай: поставь 40 — задержка станет заметной, 45 считается уже несколько секунд.
