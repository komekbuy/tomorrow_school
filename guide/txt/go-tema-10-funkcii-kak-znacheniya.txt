Запуск программы:

    go run .

------------------------------------------------------------------------------
КАК РАБОТАТЬ С ПРИМЕРАМИ
------------------------------------------------------------------------------

1. Набирай руками. Не копируй мышкой — пока печатаешь, глаз замечает
   скобки, точки и кавычки, которые при копировании проходят мимо.

2. ПЕРЕД запуском запиши, что программа выведет. Потом запусти и сверь
   с ответом под примером.

3. Не совпало — это и есть самое ценное место. Разберись, почему вышло
   именно так, и только потом иди дальше.

4. Заработало — сломай нарочно: убери кавычки, поменяй тип, поставь другой
   индекс. Прочитай, что скажет компилятор.

5. Каждый следующий пример отличается от предыдущего одним изменением —
   оно указано в заголовке. Найди его глазами до запуска.

------------------------------------------------------------------------------
ПРИМЕР 1.  Изменилось: первый, набирай целиком
------------------------------------------------------------------------------
package main

import "fmt"

func double(x int) int {
	return x * 2
}

func main() {
	fmt.Println(double(5))
}

ВЫВОД:
10

Обычная функция и обычный вызов. Дальше меняться будет только то, как до этой функции добираются.
Заметь: double(5) — это выражение, у которого есть значение 10. Именно его получил Println.

------------------------------------------------------------------------------
ПРИМЕР 2.  Изменилось: функцию положили в переменную
------------------------------------------------------------------------------
package main

import "fmt"

func double(x int) int {
	return x * 2
}

func main() {
	f := double
	fmt.Println(f(5))
	fmt.Println(double(5))
}

ВЫВОД:
10
10

double без скобок — сама функция, её просто положили в f. Теперь у одной функции два имени.
Сломай: напиши f := double(5) и оставь f(5) ниже. Прочитай ошибку — она про то, что число вызвать нельзя.

------------------------------------------------------------------------------
ПРИМЕР 3.  Изменилось: печатаем типы
------------------------------------------------------------------------------
package main

import "fmt"

func double(x int) int {
	return x * 2
}

func main() {
	f := double
	fmt.Printf("%T\n", f)
	fmt.Printf("%T\n", f(5))
	fmt.Println(f(5))
}

ВЫВОД:
func(int) int
int
10

Вот вся разница в одном экране: f имеет тип func(int) int, а f(5) — тип int. Имени параметра x в типе нет, оно на тип не влияет.

------------------------------------------------------------------------------
ПРИМЕР 4.  Изменилось: функцию передали в другую функцию
------------------------------------------------------------------------------
package main

import "fmt"

func double(x int) int {
	return x * 2
}

func square(x int) int {
	return x * x
}

func apply(f func(int) int, n int) int {
	return f(n)
}

func main() {
	fmt.Println(apply(double, 5))
	fmt.Println(apply(square, 5))
}

ВЫВОД:
10
25

apply написана один раз, а работает по двум разным правилам. Внутри неё неизвестно, что делает f — известно только, что её можно вызвать с int.
Сломай: передай double(5) вместо double.

------------------------------------------------------------------------------
ПРИМЕР 5.  Изменилось: вместо имени — безымянная функция прямо в аргументе
------------------------------------------------------------------------------
package main

import "fmt"

func apply(f func(int) int, n int) int {
	return f(n)
}

func main() {
	fmt.Println(apply(func(x int) int { return x * 2 }, 5))
	fmt.Println(apply(func(x int) int { return x + 100 }, 5))
}

ВЫВОД:
10
105

Функции double и square исчезли — правило пишется на месте. Смотри на запятую после закрывающей фигурной скобки: это граница между первым аргументом и вторым.

------------------------------------------------------------------------------
ПРИМЕР 6.  Изменилось: функции сложили в слайс
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	rules := []func(int) int{
		func(x int) int { return x * 2 },
		func(x int) int { return x + 100 },
		func(x int) int { return x * x },
	}

	fmt.Println(rules[0](5))

	for i, f := range rules {
		fmt.Println(i, f(5))
	}
}

ВЫВОД:
10
0 10
1 105
2 25

[]func(int) int — слайс, элементы которого функции. rules[0] — функция, rules[0](5) — её вызов.
Сломай: убери запятую после последней функции в списке.

------------------------------------------------------------------------------
ПРИМЕР 7.  Изменилось: правило применили ко всему слайсу чисел
------------------------------------------------------------------------------
package main

import "fmt"

func applyAll(nums []int, f func(int) int) []int {
	res := []int{}
	for _, n := range nums {
		res = append(res, f(n))
	}
	return res
}

func main() {
	nums := []int{1, 2, 3, 4}
	fmt.Println(applyAll(nums, func(x int) int { return x * 2 }))
	fmt.Println(applyAll(nums, func(x int) int { return x * x }))
	fmt.Println(nums)
}

ВЫВОД:
[2 4 6 8]
[1 4 9 16]
[1 2 3 4]

Цикл написан один раз, правил два. Третья строка показывает, что исходный слайс не тронут: результат собирали в новый.

------------------------------------------------------------------------------
ПРИМЕР 8.  Изменилось: правило теперь отвечает да/нет — другой тип
------------------------------------------------------------------------------
package main

import "fmt"

func countIf(nums []int, ok func(int) bool) int {
	c := 0
	for _, n := range nums {
		if ok(n) {
			c++
		}
	}
	return c
}

func main() {
	nums := []int{1, 2, 3, 4, 5, 6}
	fmt.Println(countIf(nums, func(x int) bool { return x%2 == 0 }))
	fmt.Println(countIf(nums, func(x int) bool { return x > 3 }))
}

ВЫВОД:
3
3

Тип правила стал func(int) bool, потому что оно отвечает на вопрос, а не считает новое значение. Тело countIf отличается от applyAll одной строкой.
Сломай: передай сюда func(x int) int { return x * 2 }.

------------------------------------------------------------------------------
ПРИМЕР 9.  Изменилось: функция возвращает функцию
------------------------------------------------------------------------------
package main

import "fmt"

func multiplier(k int) func(int) int {
	return func(x int) int {
		return x * k
	}
}

func main() {
	double := multiplier(2)
	triple := multiplier(3)

	fmt.Println(double(5))
	fmt.Println(triple(5))
	fmt.Printf("%T\n", double)
}

ВЫВОД:
10
15
func(int) int

multiplier не считает — она делает функцию. Возвращённая функция пользуется k, хотя multiplier уже закончилась: k живёт вместе с ней. У double и triple свои k, они не пересекаются.

------------------------------------------------------------------------------
ПРИМЕР 10.  Изменилось: переменная внутри меняется и живёт между вызовами
------------------------------------------------------------------------------
package main

import "fmt"

func counter() func() int {
	n := 0
	return func() int {
		n++
		return n
	}
}

func main() {
	next := counter()
	fmt.Println(next())
	fmt.Println(next())
	fmt.Println(next())

	other := counter()
	fmt.Println(other())
	fmt.Println(next())
}

ВЫВОД:
1
2
3
1
4

n создаётся при каждом вызове counter() заново, поэтому other начинает с единицы, а next продолжает с четырёх.
Сломай обязательно: перенеси n := 0 внутрь возвращаемой функции и посмотри, что станет с выводом. Это и есть проверка, понял ли ты, что именно помнит замыкание.
