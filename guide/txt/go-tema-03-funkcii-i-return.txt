КАК РАБОТАТЬ С ПРИМЕРАМИ
------------------------------------------------------------------------------

1. Набирай руками. Не копируй мышкой — пока печатаешь, глаз замечает
   скобки, точки и кавычки, которые при копировании проходят мимо.

2. ПЕРЕД запуском запиши, что программа выведет. Потом запусти и сверь
   с ответом под примером.

3. Не совпало — это и есть самое ценное место. Разберись, почему вышло
   именно так, и только потом иди дальше.

4. Заработало — сломай нарочно: убери кавычки, поменяй тип, поставь другой
   индекс. Прочитай, что скажет компилятор.

5. Каждый следующий пример отличается от предыдущего одним изменением —
   оно указано в заголовке. Найди его глазами до запуска.

------------------------------------------------------------------------------
ПРИМЕР 1.  Изменилось: первый, набирай целиком
------------------------------------------------------------------------------
package main

import "fmt"

func hello() {
	fmt.Println("hello")
}

func main() {
	hello()
}

ВЫВОД:
hello

main — точка входа, с неё всё начинается. Функция hello объявлена отдельно и срабатывает только потому, что её вызвали строкой hello().
Сломай: убери hello() из main. Программа соберётся и не напечатает ничего — объявить функцию не значит выполнить её.

------------------------------------------------------------------------------
ПРИМЕР 2.  Изменилось: у функции появился параметр
------------------------------------------------------------------------------
package main

import "fmt"

func greet(name string) {
	fmt.Println("hello,", name)
}

func main() {
	greet("Go")
	greet("world")
}

ВЫВОД:
hello, Go
hello, world

Одна функция, два вызова с разными значениями. Параметр name — переменная, которая создаётся заново на каждый вызов и живёт только внутри функции.
Сломай: вызови greet() без аргумента и прочитай ошибку.

------------------------------------------------------------------------------
ПРИМЕР 3.  Изменилось: два параметра, функция печатает результат
------------------------------------------------------------------------------
package main

import "fmt"

func showSum(a int, b int) {
	fmt.Println(a + b)
}

func main() {
	showSum(2, 3)
	showSum(10, 20)
}

ВЫВОД:
5
30

Функция считает и сразу печатает. Возврата у неё нет — после закрывающей скобки от вычисления не остаётся ничего.
Сломай: напиши x := showSum(2, 3). Ошибка showSum(2, 3) (no value) used as value — это и есть разница между печатью и возвратом.

------------------------------------------------------------------------------
ПРИМЕР 4.  Изменилось: печать заменили на return
------------------------------------------------------------------------------
package main

import "fmt"

func sum(a int, b int) int {
	return a + b
}

func main() {
	fmt.Println(sum(2, 3))
	fmt.Println(sum(10, 20))
}

ВЫВОД:
5
30

Вывод точно такой же, как в примере 3 — и это главное в теме. По экрану две функции неразличимы. Разница в том, кому ушло число: раньше — сразу на экран, теперь — в main, и уже main решает, что с ним делать.

------------------------------------------------------------------------------
ПРИМЕР 5.  Изменилось: результат подставили в другой вызов
------------------------------------------------------------------------------
package main

import "fmt"

func sum(a int, b int) int {
	return a + b
}

func main() {
	x := sum(2, 3)
	fmt.Println(x)
	fmt.Println(sum(x, sum(10, 20)))
}

ВЫВОД:
5
35

Вернувшееся значение — обычное число: его можно положить в переменную, сложить, передать в другую функцию. Внутренний sum(10, 20) выполняется первым, его 30 идёт аргументом наружу, 5 + 30 = 35. С печатающей функцией так не выйдет — подставлять нечего.

------------------------------------------------------------------------------
ПРИМЕР 6.  Изменилось: параметр стал слайсом, внутри появился цикл
------------------------------------------------------------------------------
package main

import "fmt"

func sumAll(nums []int) int {
	total := 0
	for _, n := range nums {
		total = total + n
	}
	return total
}

func main() {
	fmt.Println(sumAll([]int{1, 2, 3, 4}))
}

ВЫВОД:
10

Накопитель total создан ДО цикла: он один на всю функцию и переживает все шаги. return стоит ПОСЛЕ цикла, потому что ответ известен, только когда пройден весь слайс. Запомни эту расстановку — следующие два примера ломают её по очереди.

------------------------------------------------------------------------------
ПРИМЕР 7.  Изменилось: return переехал внутрь цикла
------------------------------------------------------------------------------
package main

import "fmt"

func sumAll(nums []int) int {
	total := 0
	for _, n := range nums {
		total = total + n
		return total
	}
	return total
}

func main() {
	fmt.Println(sumAll([]int{1, 2, 3, 4}))
}

ВЫВОД:
1

Одна строка сдвинулась — вместо 10 получилась 1. return не ждёт конца цикла, он закончил функцию на первом же шаге. Второй return после цикла здесь обязателен, иначе missing return, но управление до него не доходит никогда.

------------------------------------------------------------------------------
ПРИМЕР 8.  Изменилось: накопитель переехал внутрь цикла
------------------------------------------------------------------------------
package main

import "fmt"

func sumAll(nums []int) int {
	for _, n := range nums {
		total := 0
		total = total + n
		fmt.Println("total:", total)
	}
	return 0
}

func main() {
	fmt.Println(sumAll([]int{1, 2, 3, 4}))
}

ВЫВОД:
total: 1
total: 2
total: 3
total: 4
0

Каждый шаг создаёт НОВУЮ переменную total, равную нулю, поэтому печатается сам элемент, а не сумма. После цикла её нет вообще — возвращать пришлось ноль.
Сломай: замени return 0 на return total. Ошибка undefined: total: переменная умерла вместе с закрывающей скобкой цикла.

------------------------------------------------------------------------------
ПРИМЕР 9.  Изменилось: функция без возврата меняет свой параметр
------------------------------------------------------------------------------
package main

import "fmt"

func addTen(n int) {
	n = n + 10
	fmt.Println(n)
}

func main() {
	x := 5
	addTen(x)
	fmt.Println(x)
}

ВЫВОД:
15
5

Внутри 15, снаружи 5. В n легла копия значения, и x о ней ничего не знает. Чтобы изменение осталось, функция должна вернуть новое значение, а main — присвоить его: x = addTen(x).

------------------------------------------------------------------------------
ПРИМЕР 10.  Изменилось: функция возвращает два значения
------------------------------------------------------------------------------
package main

import "fmt"

func minMax(nums []int) (int, int) {
	lo := nums[0]
	hi := nums[0]
	for _, n := range nums {
		if n < lo {
			lo = n
		}
		if n > hi {
			hi = n
		}
	}
	return lo, hi
}

func main() {
	a, b := minMax([]int{4, 9, 1, 7})
	fmt.Println(a, b)
	fmt.Println(b - a)
}

ВЫВОД:
1 9
8

Типы перечислены в скобках, значения в return — через запятую и в том же порядке. Начальные значения берутся из nums[0], а не из нуля: с нулём максимум у отрицательного слайса нашёлся бы неверно.
Сломай: напиши v := minMax([]int{4, 9, 1, 7}) и прочитай assignment mismatch.
