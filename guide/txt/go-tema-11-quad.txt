ПОДГОТОВКА
==============================================================================

Создай папку темы и модуль — набери руками, не копируй:

    mkdir quad
    cd quad
    go mod init quad

Дальше весь код набирай в файл main.go в этой папке.
Запуск программы:

    go run .

------------------------------------------------------------------------------
КАК РАБОТАТЬ С ПРИМЕРАМИ
------------------------------------------------------------------------------

1. Набирай руками. Не копируй мышкой — пока печатаешь, глаз замечает
   скобки, точки и кавычки, которые при копировании проходят мимо.

2. ПЕРЕД запуском запиши, что программа выведет. Потом запусти и сверь
   с ответом под примером.

3. Не совпало — это и есть самое ценное место. Разберись, почему вышло
   именно так, и только потом иди дальше.

4. Заработало — сломай нарочно: убери кавычки, поменяй тип, поставь другой
   индекс. Прочитай, что скажет компилятор.

5. Каждый следующий пример отличается от предыдущего одним изменением —
   оно указано в заголовке. Найди его глазами до запуска.

------------------------------------------------------------------------------
ПРИМЕР 1.  Изменилось: первый, набирай целиком
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	x := 6
	y := 3
	for row := 1; row <= y; row++ {
		for col := 1; col <= x; col++ {
			fmt.Print("*")
		}
		fmt.Println()
	}
}

ВЫВОД:
******
******
******

Голый каркас: два цикла и один fmt.Print. Внешний цикл отвечает за строки, внутренний — за символы внутри строки, fmt.Println() закрывает строку.
Сломай: перенеси fmt.Println() внутрь внутреннего цикла и посмотри, во что превратится прямоугольник.

------------------------------------------------------------------------------
ПРИМЕР 2.  Изменилось: в клетке появился вопрос «край или середина»
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	x := 6
	y := 3
	for row := 1; row <= y; row++ {
		for col := 1; col <= x; col++ {
			if row == 1 || row == y || col == 1 || col == x {
				fmt.Print("*")
			} else {
				fmt.Print(" ")
			}
		}
		fmt.Println()
	}
}

ВЫВОД:
******
*    *
******

Циклы те же, добавилось одно условие. Четыре признака через || покрывают всю границу разом: первая строка, последняя строка, первый столбец, последний столбец.
Сломай: замени || на && и объясни, почему остались только углы.

ПРИМЕР 3.  Изменилось: верх и низ отделили от боков

		}

	}
}

ВЫВОД:
------
|    |
|    |
------

Одно условие разложилось на два: сначала спрашиваем про строку, потом про столбец. Порядок важен — else if до столбцов доходит только тогда, когда строка не крайняя.

ПРИМЕР 5.  Изменилось: код переехал в функцию, добавилась проверка размеров
------------------------------------------------------------------------------
package main

import "fmt"

func quad(x, y int) {
	if x <= 0 || y <= 0 {
		return
	}
	for row := 1; row <= y; row++ {
		for col := 1; col <= x; col++ {
			if row == 1 || row == y {
				if col == 1 || col == x {
					fmt.Print("o")
				} else {
					fmt.Print("-")
				}
			} else {
				if col == 1 || col == x {
					fmt.Print("|")
				} else {
					fmt.Print(" ")
				}
			}
		}
		fmt.Println()
	}
}

func main() {
	quad(5, 3)
	quad(0, 4)
	quad(3, -2)
	quad(1, 1)
	quad(2, 2)
}

ВЫВОД:
o---o
|   |
o---o
o
oo
oo

Пять вызовов подряд. Два из них отсекаются проверкой и не печатают ничего, три остальных — рабочие. Обрати внимание на quad(1, 1) и quad(2, 2): там первая строка и есть последняя, а первый столбец и есть последний, поэтому вся фигура состоит из углов.
Сломай: убери проверку и посмотри, что печатает quad(0, 4).

ПРИМЕР 6.  Изменилось: символы стали параметрами — одна функция вместо пяти
------------------------------------------------------------------------------
package main

import "fmt"

func quad(x, y int, corner, hor, ver string) {
	if x <= 0 || y <= 0 {
		return
	}
	for row := 1; row <= y; row++ {
		for col := 1; col <= x; col++ {
			if row == 1 || row == y {
				if col == 1 || col == x {
					fmt.Print(corner)
				} else {
					fmt.Print(hor)
				}
			} else {
				if col == 1 || col == x {
					fmt.Print(ver)
				} else {
					fmt.Print(" ")
				}
			}
		}
		fmt.Println()
	}
}

func main() {
	quad(5, 3, "o", "-", "|")
	quad(5, 3, "A", "B", "B")
}

ВЫВОД:
o---o
|   |
o---o
ABBBA
B   B
ABBBA

Логика не изменилась ни на строку — изменилось только то, откуда берутся символы. Одна функция теперь рисует любую фигуру, если передать ей нужные знаки.

ПРИМЕР 7.  Изменилось: углы сверху и снизу стали разными
------------------------------------------------------------------------------
package main

import "fmt"

func quad(x, y int, tl, tr, bl, br, hor, ver string) {
	if x <= 0 || y <= 0 {
		return
	}
	for row := 1; row <= y; row++ {
		for col := 1; col <= x; col++ {
			if row == 1 && col == 1 {
				fmt.Print(tl)
			} else if row == 1 && col == x {
				fmt.Print(tr)
			} else if row == y && col == 1 {
				fmt.Print(bl)
			} else if row == y && col == x {
				fmt.Print(br)
			} else if row == 1 || row == y {
				fmt.Print(hor)
			} else if col == 1 || col == x {
				fmt.Print(ver)
			} else {
				fmt.Print(" ")
			}
		}
		fmt.Println()
	}
}

func main() {
	quad(5, 3, "A", "A", "C", "C", "B", "B")
}

ВЫВОД:
ABBBA
B   B
CBBBC

Это quadC. Углы разъехались, поэтому вопрос «край или середина» пришлось разложить на четыре отдельные проверки — по одной на угол. Порядок проверок теперь важен: углы спрашиваются до сторон.

ВЫВОД:

A
|
|

Смотри внимательно. При высоте 1 строка одновременно первая и последняя — побеждает та проверка, что записана выше, поэтому нижние углы не появляются вовсе. При ширине 1 то же самое со столбцами. А при 1 на 1 остаётся один-единственный символ — левый верхний угол.

ПРИМЕР 10.  Изменилось: посчитали, сколько раз выполнилось тело
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	x := 5
	y := 3
	count := 0
	for row := 1; row <= y; row++ {
		for col := 1; col <= x; col++ {
			count++
			if row == 1 || row == y {
				if col == 1 || col == x {
					fmt.Print("o")
				} else {
					fmt.Print("-")
				}
			} else {
				if col == 1 || col == x {
					fmt.Print("|")
				} else {
					fmt.Print(" ")
				}
			}
		}
		fmt.Println()
	}
	fmt.Println(count)
}

ВЫВОД:
o---o
|   |
o---o
15

Пятнадцать — это 5 умножить на 3, то есть все клетки поля. Внутренний цикл прогоняется для каждой строки заново, поэтому тело срабатывает столько раз, сколько клеток в картинке.
Сломай: перенеси count := 0 внутрь внешнего цикла и посмотри, что напечатается.
