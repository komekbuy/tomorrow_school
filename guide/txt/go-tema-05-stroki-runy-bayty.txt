ПОДГОТОВКА
==============================================================================

Создай папку темы и модуль — набери руками, не копируй:

    mkdir str1
    cd str1
    go mod init str1

Дальше весь код набирай в файл main.go в этой папке.
Запуск программы:

    go run .

------------------------------------------------------------------------------
КАК РАБОТАТЬ С ПРИМЕРАМИ
------------------------------------------------------------------------------

1. Набирай руками. Не копируй мышкой — пока печатаешь, глаз замечает
   скобки, точки и кавычки, которые при копировании проходят мимо.

2. ПЕРЕД запуском запиши, что программа выведет. Потом запусти и сверь
   с ответом под примером.

3. Не совпало — это и есть самое ценное место. Разберись, почему вышло
   именно так, и только потом иди дальше.

4. Заработало — сломай нарочно: убери кавычки, поменяй тип, поставь другой
   индекс. Прочитай, что скажет компилятор.

5. Каждый следующий пример отличается от предыдущего одним изменением —
   оно указано в заголовке. Найди его глазами до запуска.

------------------------------------------------------------------------------
ПРИМЕР 1.  Изменилось: первый, набирай целиком
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Go"
	fmt.Println(s)
	fmt.Println(len(s))
}

ВЫВОД:
Go
2

Две латинские буквы — два байта. Пока len совпадает с числом букв, и это совпадение скоро закончится.
Сломай: поставь s := "Go!" и посчитай заранее, что выведет len.

------------------------------------------------------------------------------
ПРИМЕР 2.  Изменилось: добавили печать первого элемента строки
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Go"
	fmt.Println(s)
	fmt.Println(len(s))
	fmt.Println(s[0])
}

ВЫВОД:
Go
2
71

Ждал букву — получил число. s[0] достаёт байт, а 71 — код символа «G».

------------------------------------------------------------------------------
ПРИМЕР 3.  Изменилось: обернули <code>s[0]</code> в <code>string</code>
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Go"
	fmt.Println(s)
	fmt.Println(len(s))
	fmt.Println(string(s[0]))
}

ВЫВОД:
Go
2
G

string говорит: «покажи это число как символ». Значение то же — изменился только тип.

------------------------------------------------------------------------------
ПРИМЕР 4.  Изменилось: строка стала кириллической
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Дом"
	fmt.Println(s)
	fmt.Println(len(s))
	fmt.Println(string(s[0]))
}

ВЫВОД:
Дом
6
Ð

Букв три, а len шесть. И вместо «Д» вылезло «Ð» — s[0] достал только первую половину буквы, и string честно показал символ с этим кодом. Это и есть главная ловушка темы.

------------------------------------------------------------------------------
ПРИМЕР 5.  Изменилось: вместо одного байта печатаем все
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Дом"
	fmt.Println(s)
	fmt.Println(len(s))
	fmt.Println([]byte(s))
}

ВЫВОД:
Дом
6
[208 148 208 190 208 188]

Вот вся строка изнутри: шесть чисел на три буквы, по два числа на букву. Никаких букв в памяти нет.
Сломай: поставь s := "Go" и сравни — там будет два числа.

------------------------------------------------------------------------------
ПРИМЕР 6.  Изменилось: вместо печати байтов — цикл <code>range</code>
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Дом"
	fmt.Println(s)
	fmt.Println(len(s))
	for i, c := range s {
		fmt.Println(i, string(c))
	}
}

ВЫВОД:
Дом
6
0 Д
2 о
4 м

Буквы наконец целые. Но номера идут 0, 2, 4 — i считает байты, а не шаги. Шагов было три.

------------------------------------------------------------------------------
ПРИМЕР 7.  Изменилось: <code>range</code> идёт по <code>[]rune(s)</code>, а не по строке
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Дом"
	fmt.Println(s)
	fmt.Println(len(s))
	for i, c := range []rune(s) {
		fmt.Println(i, string(c))
	}
}

ВЫВОД:
Дом
6
0 Д
1 о
2 м

Одно изменение — и номера стали 0, 1, 2. По слайсу рун range идёт как по обычному списку: индекс — это номер символа. Так делают, когда нужен именно порядковый номер буквы.

------------------------------------------------------------------------------
ПРИМЕР 8.  Изменилось: правим руну и собираем строку обратно
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Дом"
	r := []rune(s)
	r[0] = 'Т'
	fmt.Println(s)
	fmt.Println(string(r))
}

ВЫВОД:
Дом
Том

Исходная строка не изменилась — правили копию, разложенную на руны. Сломай: напиши s[0] = 'Т' напрямую и прочитай ошибку.

------------------------------------------------------------------------------
ПРИМЕР 9.  Изменилось: вместо правки — сборка новой строки накопителем
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Дом"
	res := ""
	for _, c := range s {
		res = string(c) + res
	}
	fmt.Println(s)
	fmt.Println(res)
}

ВЫВОД:
Дом
моД

Каждый новый символ приписывается слева, поэтому строка растёт задом наперёд.
Сломай: поменяй на res = res + string(c) и посмотри, что выйдет.

------------------------------------------------------------------------------
ПРИМЕР 10.  Изменилось: добавили срез и сравнение строк
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	s := "Дом"
	res := ""
	for _, c := range s {
		res = string(c) + res
	}
	fmt.Println(res)
	fmt.Println(s[2:], s[:2])
	fmt.Println(s == "Дом", s < "Кот")
}

ВЫВОД:
моД
ом Д
true true

s[2:] даёт «ом», потому что буква «Д» заняла байты 0 и 1. s < "Кот" — true: сравнение идёт по кодам, «Д» раньше «К».
Сломай: напиши s[1:] и посмотри на обрубок.
