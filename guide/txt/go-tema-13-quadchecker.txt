ПОДГОТОВКА
==============================================================================

Создай папку темы и модуль — набери руками, не копируй:

    mkdir quadchecker
    cd quadchecker
    go mod init quadchecker

Дальше весь код набирай в файл main.go в этой папке.
Запуск программы:

    go run .

------------------------------------------------------------------------------
КАК РАБОТАТЬ С ПРИМЕРАМИ
------------------------------------------------------------------------------

1. Набирай руками. Не копируй мышкой — пока печатаешь, глаз замечает
   скобки, точки и кавычки, которые при копировании проходят мимо.

2. ПЕРЕД запуском запиши, что программа выведет. Потом запусти и сверь
   с ответом под примером.

3. Не совпало — это и есть самое ценное место. Разберись, почему вышло
   именно так, и только потом иди дальше.

4. Заработало — сломай нарочно: убери кавычки, поменяй тип, поставь другой
   индекс. Прочитай, что скажет компилятор.

5. Каждый следующий пример отличается от предыдущего одним изменением —
   оно указано в заголовке. Найди его глазами до запуска.

------------------------------------------------------------------------------
ПРИМЕР 1.  Изменилось: первый, набирай целиком
------------------------------------------------------------------------------
package main

import "fmt"

type quad struct {
	name string
	tl   rune
}

func main() {
	a := quad{name: "quadA", tl: 'o'}
	fmt.Println(a.name)
}

ВЫВОД:
quadA

type ... struct ничего не создаёт — он объявляет тип. Переменная появляется строкой a := quad{...}. К полю обращаемся через точку: a.name.
Сломай: напиши a.quad и прочитай ошибку.

------------------------------------------------------------------------------
ПРИМЕР 2.  Изменилось: печатаем и второе поле
------------------------------------------------------------------------------
package main

import "fmt"

type quad struct {
	name string
	tl   rune
}

func main() {
	a := quad{name: "quadA", tl: 'o'}

ВЫВОД:
quadA
111

Второе поле напечаталось числом. rune — это число, код символа; у буквы «o» он равен 111. Никакой ошибки здесь нет, так и устроено.

ПРИМЕР 3.  Изменилось: ту же руну показали символом

package main

ВЫВОД:
111

string(...) превращает число в символ с таким кодом. Значение в памяти не изменилось — изменился только способ его показать.

------------------------------------------------------------------------------
ПРИМЕР 4.  Изменилось: структур стало несколько — появился слайс
------------------------------------------------------------------------------
package main

import "fmt"

type quad struct {
	name string
	tl   rune
}

func main() {
	quads := []quad{
		{"quadA", 'o'},
		{"quadB", '/'},
	}
	for _, q := range quads {
		fmt.Println(q.name, string(q.tl))
	}
}

ВЫВОД:
quadA o
quadB /

Имена полей можно не писать, если значения идут в том же порядке, что в объявлении типа. Перебор — обычный range, номер не нужен, поэтому нижнее подчёркивание.

ПРИМЕР 5.  Изменилось: полей стало шесть — фигура описана целиком

ВЫВОД:
o - |

Четыре угла, горизонталь и вертикаль — этих шести символов хватает, чтобы описать любую из пяти фигур. Вся разница между quadA и quadE именно здесь.

ПРИМЕР 6.  Изменилось: появилась функция про клетку — пока только углы
------------------------------------------------------------------------------
package main

import "fmt"

type quad struct {
	name string
	tl   rune
	tr   rune
	bl   rune
	br   rune
	hor  rune
	ver  rune
}

func cell(q quad, row, col, w, h int) rune {
	if row == 0 && col == 0 {
		return q.tl
	}
	if row == 0 && col == w-1 {
		return q.tr
	}
	return ' '
}

func main() {
	a := quad{"quadA", 'o', 'o', 'o', 'o', '-', '|'}
	fmt.Printf("%q %q %q\n", string(cell(a, 0, 0, 3, 3)), string(cell(a, 0, 2, 3, 3)), string(cell(a, 1, 1, 3, 3)))
}

ВЫВОД:
"o" "o" " "

Функция смотрит на адрес клетки, а не на символы. w-1 — последний столбец: счёт с нуля, поэтому в ширине 3 последний это второй. %q печатает в кавычках, чтобы пробел было видно.

ПРИМЕР 7.  Изменилось: добавились нижние углы и обе стороны
------------------------------------------------------------------------------
package main

import "fmt"

type quad struct {
	name string
	tl   rune
	tr   rune
	bl   rune
	br   rune
	hor  rune
	ver  rune
}

func cell(q quad, row, col, w, h int) rune {
	if row == 0 && col == 0 {
		return q.tl
	}
	if row == 0 && col == w-1 {
		return q.tr
	}
	if row == h-1 && col == 0 {
		return q.bl
	}
	if row == h-1 && col == w-1 {
		return q.br
	}
	if row == 0 || row == h-1 {
		return q.hor
	}
	if col == 0 || col == w-1 {
		return q.ver
	}
	return ' '
}

func main() {
	a := quad{"quadA", 'o', 'o', 'o', 'o', '-', '|'}
	fmt.Printf("%q %q %q %q\n", string(cell(a, 0, 1, 3, 3)), string(cell(a, 1, 0, 3, 3)), string(cell(a, 2, 2, 3, 3)), string(cell(a, 1, 1, 3, 3)))
}

ВЫВОД:
"-" "|" "o" " "

Шесть проверок идут сверху вниз, срабатывает первая подошедшая. Сначала все четыре угла, потом стороны, в конце пробел.
Сломай: подними проверку row == 0 || row == h-1 выше углов — все углы превратятся в горизонталь.

ПРИМЕР 10.  Изменилось: строк стало много — и мы их сравниваем
------------------------------------------------------------------------------
package main

import "fmt"

type quad struct {
	name string
	tl   rune
	tr   rune
	bl   rune
	br   rune
	hor  rune
	ver  rune
}

func cell(q quad, row, col, w, h int) rune {
	if row == 0 && col == 0 {
		return q.tl
	}
	if row == 0 && col == w-1 {
		return q.tr
	}
	if row == h-1 && col == 0 {
		return q.bl
	}
	if row == h-1 && col == w-1 {
		return q.br
	}
	if row == 0 || row == h-1 {
		return q.hor
	}
	if col == 0 || col == w-1 {
		return q.ver
	}
	return ' '
}

func main() {
	a := quad{"quadA", 'o', 'o', 'o', 'o', '-', '|'}
	want := []string{"o---o", "|   |", "o---o"}
	w, h := 5, 3
	same := true
	for row := 0; row < h; row++ {
		line := make([]rune, w)
		for col := 0; col < w; col++ {
			line[col] = cell(a, row, col, w, h)
		}
		fmt.Println(string(line))
		if string(line) != want[row] {
			same = false
		}
	}
	fmt.Println(same)
}

ВЫВОД:
o---o
|   |
o---o
true

Вот и вся программа в миниатюре: нарисовали своё, сравнили с чужим, сказали да или нет. В настоящем match отличие одно — при первом же расхождении там стоит return false, и остальные строки не считаются вовсе.
Сломай: поменяй want на {"o---o", "|   |", "x---x"}.
