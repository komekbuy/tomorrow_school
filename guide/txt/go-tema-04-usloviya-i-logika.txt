ПОДГОТОВКА
==============================================================================

Создай папку темы и модуль — набери руками, не копируй:

    mkdir if1
    cd if1
    go mod init if1

Дальше весь код набирай в файл main.go в этой папке.
Запуск программы:

    go run .

------------------------------------------------------------------------------
КАК РАБОТАТЬ С ПРИМЕРАМИ
------------------------------------------------------------------------------

1. Набирай руками. Не копируй мышкой — пока печатаешь, глаз замечает
   скобки, точки и кавычки, которые при копировании проходят мимо.

2. ПЕРЕД запуском запиши, что программа выведет. Потом запусти и сверь
   с ответом под примером.

3. Не совпало — это и есть самое ценное место. Разберись, почему вышло
   именно так, и только потом иди дальше.

4. Заработало — сломай нарочно: убери кавычки, поменяй тип, поставь другой
   индекс. Прочитай, что скажет компилятор.

5. Каждый следующий пример отличается от предыдущего одним изменением —
   оно указано в заголовке. Найди его глазами до запуска.

------------------------------------------------------------------------------
ПРИМЕР 1.  Изменилось: первый, набирай целиком
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	n := -7
	if n > 0 {
		fmt.Println("positive")
	}
	fmt.Println("done")
}

ВЫВОД:
done

Условие ложно — тело if пропущено целиком, программа пошла дальше. Ни ошибки, ни предупреждения: пропуск ветки — нормальная работа.
Сломай: поставь if n вместо if n > 0 и прочитай ошибку.

------------------------------------------------------------------------------
ПРИМЕР 2.  Изменилось: добавили else
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	n := -7
	if n > 0 {
		fmt.Println("positive")
	} else {
		fmt.Println("not positive")
	}
	fmt.Println("done")
}

ВЫВОД:
not positive
done

Теперь ветки две, и одна из них выполнится обязательно. Сломай: перенеси else на новую строку под } — не соберётся.

------------------------------------------------------------------------------
ПРИМЕР 3.  Изменилось: между ними встала ветка else if
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	n := -7
	if n > 0 {
		fmt.Println("positive")
	} else if n == 0 {
		fmt.Println("zero")
	} else {
		fmt.Println("negative")
	}
	fmt.Println("done")
}

ВЫВОД:
negative
done

Проверки идут сверху вниз: первая ложна, вторая ложна, сработал else. Ровно одна ветка из трёх.

------------------------------------------------------------------------------
ПРИМЕР 4.  Изменилось: вместо веток печатаем сами сравнения
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	n := -7
	fmt.Println(n > 0)
	fmt.Println(n == 0)
	ok := n < 0
	fmt.Println(ok)
	fmt.Printf("%T\n", ok)
}

ВЫВОД:
false
false
true
bool

Сравнение — это выражение со значением, а не часть if. Его можно напечатать, положить в переменную, вернуть из функции. Тип у него bool.

------------------------------------------------------------------------------
ПРИМЕР 5.  Изменилось: два сравнения соединили через &&
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	n := 5
	fmt.Println(n >= 0 && n <= 9)
	n = 42
	fmt.Println(n >= 0 && n <= 9)
}

ВЫВОД:
true
false

Это и есть диапазон: две границы, обе про n, соединены через &&. У 42 первая часть истинна, вторая нет — значит, всё условие ложно.

------------------------------------------------------------------------------
ПРИМЕР 6.  Изменилось: перед условием появился !
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	n := 5
	fmt.Println(!(n >= 0 && n <= 9))
	n = 42
	fmt.Println(!(n >= 0 && n <= 9))
}

ВЫВОД:
false
true

Ответы перевернулись. Скобки здесь обязательны: без них ! взял бы только n, а к числу он неприменим — не соберётся.

------------------------------------------------------------------------------
ПРИМЕР 7.  Изменилось: то же самое переписали через ||, без !
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	n := 5
	fmt.Println(n < 0 || n > 9)
	n = 42
	fmt.Println(n < 0 || n > 9)
}

ВЫВОД:
false
true

Вывод совпал с прошлым примером до символа — это одно и то же условие. «Не (внутри диапазона)» равно «ниже нижней границы или выше верхней». Знаки при этом развернулись: >= стал <, <= стал >.

------------------------------------------------------------------------------
ПРИМЕР 8.  Изменилось: || заменили на && — один знак
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	n := 5
	fmt.Println(n < 0 && n > 9)
	n = 42
	fmt.Println(n < 0 && n > 9)
}

ВЫВОД:
false
false

Два false — и так будет при любом числе. Ни одно число не меньше нуля и больше девяти одновременно. Это самая частая ошибка темы, и компилятор её не видит.

------------------------------------------------------------------------------
ПРИМЕР 9.  Изменилось: появилась функция, которая сообщает, что её вызвали
------------------------------------------------------------------------------
package main

import "fmt"

func check(name string, result bool) bool {
	fmt.Println("check", name)
	return result
}

func main() {
	fmt.Println(check("A", true) || check("B", true))
	fmt.Println(check("A", false) && check("B", false))
}

ВЫВОД:
check A
true
check A
false

«check B» не напечаталось ни разу. У || левая часть дала true, у && — false: ответ уже известен, правую часть Go просто не вызывает.

------------------------------------------------------------------------------
ПРИМЕР 10.  Изменилось: сравниваем не числа, а руны
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	c := '5'
	fmt.Println(c >= '0' && c <= '9')
	fmt.Println(c >= 0 && c <= 9)
	if c >= '0' && c <= '9' {
		fmt.Println("digit", c-'0')
	} else {
		fmt.Println("not a digit")
	}
}

ВЫВОД:
true
false
digit 5

Вторая строка собралась и дала false: в c лежит 53, а не 5. Разница между двумя строками — две одинарные кавычки.
Сломай: поставь c := 'x' и посмотри, что напечатается.
