    mkdir if1
    cd if1

From here on, type all code into main.go in that folder.
To run the program:

    go run .

------------------------------------------------------------------------------
HOW TO WORK WITH THE EXAMPLES
------------------------------------------------------------------------------

1. Type it out. Don't copy-paste — while you type, your eye catches the
   brackets, dots and quotes that copying slides right past.

2. BEFORE running, write down what it will print. Then run it and compare
   with the answer under the example.

3. A mismatch is the valuable part. Work out why it came out that way
   before moving on.

4. Once it works, break it on purpose: drop the quotes, change the type,
   use a different index. Read what the compiler says.

5. Each example differs from the previous one by a single change — it is
   named in the heading. Spot it before you run anything.

EXAMPLES

------------------------------------------------------------------------------
EXAMPLE 1.  What changed: the first one, type it all
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	n := -7
	if n > 0 {
		fmt.Println("positive")
	}
	fmt.Println("done")
}

OUTPUT:
done

The condition is false — the if body is skipped entirely and the program moves on. No error, no warning: skipping a branch is normal behaviour.
Break it: write if n instead of if n > 0 and read the error.

------------------------------------------------------------------------------
EXAMPLE 2.  What changed: added an else
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	n := -7
	if n > 0 {
		fmt.Println("positive")
	} else {
		fmt.Println("not positive")
	}
	fmt.Println("done")
}

OUTPUT:
not positive
done

Now there are two branches and exactly one of them will run. Break it: move else to its own line below the } — it won't compile.

------------------------------------------------------------------------------
EXAMPLE 3.  What changed: an else if branch went in between
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	n := -7
	if n > 0 {
		fmt.Println("positive")
	} else if n == 0 {
		fmt.Println("zero")
	} else {
		fmt.Println("negative")
	}
	fmt.Println("done")
}

OUTPUT:
negative
done

Checks run top to bottom: the first is false, the second is false, so else fires. Exactly one branch out of three.

------------------------------------------------------------------------------
EXAMPLE 4.  What changed: instead of branching we print the comparisons themselves
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	n := -7
	fmt.Println(n > 0)
	fmt.Println(n == 0)
	ok := n < 0
	fmt.Println(ok)
	fmt.Printf("%T\n", ok)
}

OUTPUT:
false
false
true
bool

A comparison is an expression with a value, not a piece of if syntax. You can print it, store it, return it from a function. Its type is bool.

------------------------------------------------------------------------------
EXAMPLE 5.  What changed: two comparisons joined with &&
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	n := 5
	fmt.Println(n >= 0 && n <= 9)
	n = 42
	fmt.Println(n >= 0 && n <= 9)
}

OUTPUT:
true
false

That is a range: two bounds, both about n, joined by &&. For 42 the first part is true and the second is not, so the whole condition is false.

------------------------------------------------------------------------------
EXAMPLE 6.  What changed: a ! appeared in front of the condition
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	n := 5
	fmt.Println(!(n >= 0 && n <= 9))
	n = 42
	fmt.Println(!(n >= 0 && n <= 9))
}

OUTPUT:
false
true

The answers flipped. The parentheses are required: without them ! would grab just n, and it doesn't apply to a number — no compile.

------------------------------------------------------------------------------
EXAMPLE 7.  What changed: the same thing rewritten with ||, no !
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	n := 5
	fmt.Println(n < 0 || n > 9)
	n = 42
	fmt.Println(n < 0 || n > 9)
}

OUTPUT:
false
true

The output matches the previous example exactly — it is the same condition. “Not (inside the range)” equals “below the lower bound or above the upper one”. Note the signs flipped: >= became <, <= became >.

------------------------------------------------------------------------------
EXAMPLE 8.  What changed: || replaced by && — a single sign
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	n := 5
	fmt.Println(n < 0 && n > 9)
	n = 42
	fmt.Println(n < 0 && n > 9)
}

OUTPUT:
false
false

Two false results — and it stays that way for any number. No number is both below zero and above nine. This is the most common mistake in the topic, and the compiler does not see it.

------------------------------------------------------------------------------
EXAMPLE 9.  What changed: a function appeared that announces its own call
------------------------------------------------------------------------------
package main

import "fmt"

func check(name string, result bool) bool {
	fmt.Println("check", name)
	return result
}

func main() {
	fmt.Println(check("A", true) || check("B", true))
	fmt.Println(check("A", false) && check("B", false))
}

OUTPUT:
check A
true
check A
false

“check B” never printed. For || the left side gave true, for && it gave false: the answer is settled, so Go never calls the right side at all.

------------------------------------------------------------------------------
EXAMPLE 10.  What changed: comparing runes instead of numbers
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	c := '5'
	fmt.Println(c >= '0' && c <= '9')
	fmt.Println(c >= 0 && c <= 9)
	if c >= '0' && c <= '9' {
		fmt.Println("digit", c-'0')
	} else {
		fmt.Println("not a digit")
	}
}

OUTPUT:
true
false
digit 5

The second line compiled and printed false: c holds 53, not 5. The difference between the two lines is two single quotes.
Break it: set c := 'x' and see what comes out.
