ПОДГОТОВКА
==============================================================================

Создай папку темы и модуль — набери руками, не копируй:

    mkdir struct1
    cd struct1
    go mod init struct1

Дальше весь код набирай в файл main.go в этой папке.
Запуск программы:

    go run .

------------------------------------------------------------------------------
КАК РАБОТАТЬ С ПРИМЕРАМИ
------------------------------------------------------------------------------

1. Набирай руками. Не копируй мышкой — пока печатаешь, глаз замечает
   скобки, точки и кавычки, которые при копировании проходят мимо.

2. ПЕРЕД запуском запиши, что программа выведет. Потом запусти и сверь
   с ответом под примером.

3. Не совпало — это и есть самое ценное место. Разберись, почему вышло
   именно так, и только потом иди дальше.

4. Заработало — сломай нарочно: убери кавычки, поменяй тип, поставь другой
   индекс. Прочитай, что скажет компилятор.

5. Каждый следующий пример отличается от предыдущего одним изменением —
   оно указано в заголовке. Найди его глазами до запуска.

------------------------------------------------------------------------------
ПРИМЕР 1.  Изменилось: первый, набирай целиком
------------------------------------------------------------------------------
package main

import "fmt"

type Person struct {
	name string
	age  int
}

func main() {
	var p Person
	fmt.Println(p)
	fmt.Println(p.name == "", p.age)
}

ВЫВОД:
{ 0}
true 0

Структуру создали, но ничего не положили — внутри не мусор, а нулевые значения полей. Пустая строка печатается как ничего, поэтому в выводе пробел между скобкой и нулём.
Сломай: добавь в тип третье поле ok bool и посмотри, что появится в выводе.

------------------------------------------------------------------------------
ПРИМЕР 2.  Изменилось: структуру создали сразу со значениями
------------------------------------------------------------------------------
package main

import "fmt"

type Person struct {
	name string
	age  int
}

func main() {
	p := Person{"Bob", 30}
	fmt.Println(p)
	fmt.Println(p.name == "", p.age)
}

ВЫВОД:
{Bob 30}
false 30

Значения без имён идут строго по порядку полей типа.
Сломай: убери 30, оставь Person{"Bob"} — получишь too few values in struct literal.

------------------------------------------------------------------------------
ПРИМЕР 3.  Изменилось: значения задали по именам полей
------------------------------------------------------------------------------
package main

import "fmt"

type Person struct {
	name string
	age  int
}

func main() {
	p := Person{name: "Bob"}
	fmt.Println(p)
	fmt.Println(p.name == "", p.age)
}

ВЫВОД:
{Bob 0}
false 0

С именами можно указать не все поля — пропущенные становятся нулевыми. Такая запись переживает добавление нового поля в тип, а запись из примера 2 — нет.

------------------------------------------------------------------------------
ПРИМЕР 4.  Изменилось: поле поменяли после создания
------------------------------------------------------------------------------
package main

import "fmt"

type Person struct {
	name string
	age  int
}

func main() {
	p := Person{name: "Bob"}
	p.age = 30
	fmt.Println(p)
	fmt.Println(p.name, p.age)
}

ВЫВОД:
{Bob 30}
Bob 30

Точка одинаково работает и на чтение, и на запись. Запомни этот вывод — следующий пример делает ровно то же самое, но результат будет другим.

------------------------------------------------------------------------------
ПРИМЕР 5.  Изменилось: то же изменение вынесли в функцию
------------------------------------------------------------------------------
package main

import "fmt"

type Person struct {
	name string
	age  int
}

func setAge(p Person) {
	p.age = 30
}

func main() {
	p := Person{name: "Bob"}
	setAge(p)
	fmt.Println(p)
	fmt.Println(p.name, p.age)
}

ВЫВОД:
{Bob 0}
Bob 0

Ноль вместо тридцати. Строка p.age = 30 выполнилась — но у копии, которая живёт только внутри функции. Ни ошибки, ни предупреждения.
Сломай: добавь fmt.Println(p) последней строкой внутри setAge — там будет 30.

------------------------------------------------------------------------------
ПРИМЕР 6.  Изменилось: параметр функции стал указателем
------------------------------------------------------------------------------
package main

import "fmt"

type Person struct {
	name string
	age  int
}

func setAge(p *Person) {
	p.age = 30
}

func main() {
	p := Person{name: "Bob"}
	setAge(&p)
	fmt.Println(p)
	fmt.Println(p.name, p.age)
}

ВЫВОД:
{Bob 30}
Bob 30

Отличие от прошлого примера — два символа: * в объявлении и & в вызове. Внутри функции по-прежнему копия, но копия адреса, а адрес ведёт к оригиналу.
Сломай: убери & в вызове и прочитай ошибку.

------------------------------------------------------------------------------
ПРИМЕР 7.  Изменилось: вместо функции — сам указатель
------------------------------------------------------------------------------
package main

import "fmt"

type Person struct {
	name string
	age  int
}

func main() {
	p := Person{name: "Bob", age: 30}
	q := &p
	fmt.Println(q == &p)
	fmt.Println(*q)
	fmt.Println(q.name, (*q).name)
	q.age = 31
	fmt.Println(p.age)
}

ВЫВОД:
true
{Bob 30}
Bob Bob
31

q.name и (*q).name — одна и та же запись, Go подставляет звёздочку сам. Последняя строка — суть указателя: писали в q, изменилось в p.
Сломай: напечатай q без звёздочки — увидишь &{Bob 30}.

------------------------------------------------------------------------------
ПРИМЕР 8.  Изменилось: появился второй указатель, без адреса
------------------------------------------------------------------------------
package main

import "fmt"

type Person struct {
	name string
	age  int
}

func main() {
	p := Person{name: "Bob", age: 30}
	q := &p
	var z *Person
	fmt.Println(q == nil, z == nil)
	fmt.Println(*q)
	fmt.Println(q, z)
}

ВЫВОД:
false true
{Bob 30}
&{Bob 30} <nil>

z объявлен, но адреса не получил — внутри nil. Печатать его безопасно, а вот z.name уронит программу.
Сломай обязательно: добавь fmt.Println(z.name) и прочитай текст падения — это panic, а не ошибка сборки.

------------------------------------------------------------------------------
ПРИМЕР 9.  Изменилось: внутрь структуры вложили другую
------------------------------------------------------------------------------
package main

import "fmt"

type Address struct {
	city string
	zip  int
}

type Person struct {
	name string
	age  int
	addr Address
}

func main() {
	var p Person
	fmt.Println(p)
	p.name = "Bob"
	p.addr.city = "Astana"
	fmt.Println(p)
	fmt.Println(p.addr.city, p.addr.zip)
}

ВЫВОД:
{ 0 { 0}}
{Bob 0 {Astana 0}}
Astana 0

Вложенная структура печатается своими скобками — по ним и читай вывод. Нулевое значение раскрывается вглубь: у Address тоже все поля нулевые.

------------------------------------------------------------------------------
ПРИМЕР 10.  Изменилось: структуры сложили в слайс
------------------------------------------------------------------------------
package main

import "fmt"

type Person struct {
	name string
	age  int
}

func main() {
	people := []Person{{"Bob", 30}, {"Ann", 25}}

	for _, v := range people {
		v.age = 0
	}
	fmt.Println(people)

	for i := range people {
		people[i].age = 0
	}
	fmt.Println(people)
}

ВЫВОД:
[{Bob 30} {Ann 25}]
[{Bob 0} {Ann 0}]

Два одинаковых на вид цикла, разный результат. В первом v — копия элемента, обнулили её. Во втором people[i] — сам элемент.
Внутри []Person{...} имя типа можно не повторять: {"Bob", 30} вместо Person{"Bob", 30}.
