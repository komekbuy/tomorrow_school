ПОДГОТОВКА
==============================================================================

Создай папку темы и модуль — набери руками, не копируй:

    mkdir loop1
    cd loop1
    go mod init loop1

Дальше весь код набирай в файл main.go в этой папке.
Запуск программы:

    go run .

------------------------------------------------------------------------------
КАК РАБОТАТЬ С ПРИМЕРАМИ
------------------------------------------------------------------------------

1. Набирай руками. Не копируй мышкой — пока печатаешь, глаз замечает
   скобки, точки и кавычки, которые при копировании проходят мимо.

2. ПЕРЕД запуском запиши, что программа выведет. Потом запусти и сверь
   с ответом под примером.

3. Не совпало — это и есть самое ценное место. Разберись, почему вышло
   именно так, и только потом иди дальше.

4. Заработало — сломай нарочно: убери кавычки, поменяй тип, поставь другой
   индекс. Прочитай, что скажет компилятор.

5. Каждый следующий пример отличается от предыдущего одним изменением —
   оно указано в заголовке. Найди его глазами до запуска.

------------------------------------------------------------------------------
ПРИМЕР 1.  Изменилось: первый, набирай целиком
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	for i := 0; i < 5; i++ {
		fmt.Println(i)
	}
}

ВЫВОД:
0
1
2
3
4

Пять строк, а не шесть: счётчик начал с нуля и остановился на четырёх — пятёрка условие i < 5 уже не прошла.
Сломай: убери i++ и запусти. Программа зависнет — останавливай Ctrl+C.

ВЫВОД:

Изменился один символ — шагов стало шесть вместо пяти. Компилятор здесь молчит: оба варианта законны. Это и есть ошибка на единицу.

------------------------------------------------------------------------------
ПРИМЕР 3.  Изменилось: печатаем звёздочку вместо счётчика
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	for i := 0; i <= 5; i++ {
		fmt.Print("*")
	}
	fmt.Println()
}

ВЫВОД:
******

Звёздочек шесть, потому что нестрогая граница из прошлого примера осталась на месте. Теперь i в теле нет — он только считает, а на экран не попадает.

------------------------------------------------------------------------------
ПРИМЕР 4.  Изменилось: вернули строгую границу
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	for i := 0; i < 5; i++ {
		fmt.Print("*")
	}
	fmt.Println()
}

ВЫВОД:
*****

Пять звёздочек. Тело не менялось вообще — количество повторов задаётся только заголовком цикла.

------------------------------------------------------------------------------
ПРИМЕР 5.  Изменилось: вокруг появился второй цикл
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	for row := 0; row < 3; row++ {
		for i := 0; i < 5; i++ {
			fmt.Print("*")
		}
		fmt.Println()
	}
}

ВЫВОД:
*****
*****
*****

Внутренний цикл проходит целиком на каждом шаге внешнего: 3 × 5 = 15 звёздочек. fmt.Println() переехал в тело внешнего цикла — по одному разу на строку.

------------------------------------------------------------------------------
ПРИМЕР 6.  Изменилось: вместо звёздочки печатаем внутренний счётчик
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	for row := 0; row < 3; row++ {
		for i := 0; i < 5; i++ {
			fmt.Print(i)
		}
		fmt.Println()
	}
}

ВЫВОД:
01234
01234
01234

Строки одинаковые — значит, внутренний счётчик каждый раз начинается заново. Он создаётся на каждом шаге внешнего цикла и умирает вместе с ним.

------------------------------------------------------------------------------
ПРИМЕР 8.  Изменилось: добавлен break (перевод строки вернули на место)
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	for row := 0; row < 3; row++ {
		for i := 0; i < 5; i++ {
			if i == 3 {
				break
			}
			fmt.Print(i)
		}
		fmt.Println()
	}
}

ВЫВОД:
012
012
012

Внутренний цикл заявлен до пяти, а обрывается на трёх. Важно: break вышел только из внутреннего цикла — внешний спокойно сделал все три шага.

------------------------------------------------------------------------------
ПРИМЕР 9.  Изменилось: break стал continue
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	for row := 0; row < 3; row++ {
		for i := 0; i < 5; i++ {
			if i == 3 {
				continue
			}
			fmt.Print(i)
		}
		fmt.Println()
	}
}

ВЫВОД:
0124
0124
0124

Было 012, стало 0124. break обрывает цикл, continue пропускает один шаг и идёт дальше — тройка исчезла, четвёрка осталась.

------------------------------------------------------------------------------
ПРИМЕР 10.  Изменилось: цикл со счётчиком заменили на range
------------------------------------------------------------------------------
package main

import "fmt"

func main() {
	nums := []int{10, 20, 30}
	for i, v := range nums {
		fmt.Println(i, v)
	}
	for i, c := range "Go!" {
		fmt.Println(i, c, string(c))
	}
}

ВЫВОД:
0 10
1 20
2 30
0 71 G
1 111 o
2 33 !

Первая переменная — номер, вторая — значение. По строке значение приходит руной, то есть числом: 71 и G в одной строке — это одно и то же.
Сломай: убери v и оставь for i := range nums — вывод станет 0, 1, 2.
