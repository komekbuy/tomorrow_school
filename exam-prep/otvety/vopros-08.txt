------------------------------------------------------------------------------
  КАК ДУМАТЬ НАД ЗАДАЧЕЙ (читать до кода)
------------------------------------------------------------------------------
  Дано число и основание, надо получить строку — запись этого числа в данной
  системе счисления. Запись числа в системе с основанием B устроена так:
  число = ... + d2*B*B + d1*B + d0, где каждая цифра d от 0 до B-1. Значит
  последнюю цифру d0 можно вытащить как остаток от деления на B, а всё
  остальное — это число, делённое на B нацело; повторяем ту же операцию,
  пока число не станет нулём. Цифры при этом выходят в обратном порядке:
  сначала последняя, потом предпоследняя. Значит каждую новую цифру надо
  приписывать НЕ в конец накопленной строки, а в начало — тогда порядок
  восстановится сам, и разворачивать строку в конце не придётся. Цифра — это
  число от 0 до 15, а нужен символ; для перевода берём строку-таблицу
  "0123456789ABCDEF", где позиция символа равна его значению, и обращаемся
  по индексу. Ноль — отдельный случай: цикл "пока число не ноль" для нуля не
  выполнится ни разу и вернёт пустую строку, поэтому ноль обрабатывается до
  цикла. С отрицательными числами есть подвох: в Go остаток от деления
  отрицательного числа тоже отрицательный, например -42 % 4 равно -2, а
  индекс -2 в строке — паника. Поэтому знак запоминается отдельной
  переменной bool, а у остатка внутри цикла берётся модуль. Менять сам value
  на -value в начале не нужно и опасно: для самого маленького int такое
  отрицание переполняется, а вариант с модулем остатка работает и там. В
  конце, если знак был минусовым, приписываем "-" один раз перед всей
  строкой.

package piscine

import (
	"strconv"
	"strings"

func ItoaBase(value, base int) string {
  Два параметра ОДНОГО типа записаны через запятую с одним указанием типа в конце: value, base int означает, что оба int. Писать (value int, base int) можно, но длиннее.
  value — само число, base — основание системы счисления. Возвращается строка.

	if base < 2 || base > 16 {
  Защита от плохого основания. || — «или», тоже ленивое: если левая часть истинна, правая не вычисляется.

		return ""
  Ранний выход с пустой строкой.
  🔴 Эта проверка не декорация. strconv.FormatInt при основании вне диапазона 2..36 роняет программу (panic). Верхняя граница здесь жёстче — 16, потому что этого требует условие задачи.

	}
  Конец if.


  Пустая строка перед return — просто отступ для читаемости, на работу не влияет.

	return strings.ToUpper(strconv.FormatInt(int64(value), base))
  Читается изнутри наружу:
  int64(value) — перевод типа. FormatInt принимает только int64, а value у нас int. Без этого перевода код не скомпилируется — Go не переводит числовые типы сам;
  strconv.FormatInt(число, основание) — делает всю работу задания: переводит число в запись по нужному основанию и возвращает строку. Деление с остатком, накопление цифр и разворот в обратном порядке — всё внутри неё. Минус перед отрицательными числами она ставит сама;
  strings.ToUpper(...) — поднимает буквы в верхний регистр. Он нужен потому, что FormatInt выдаёт буквы МАЛЕНЬКИМИ (ff), а по условию требуются заглавные (FF). Цифры и знак минус ToUpper не трогает.

}
  Конец функции.

  * int — целое число со знаком, на 64-битной машине от -9223372036854775808
  до 9223372036854775807.
  * string — строка, неизменяемая последовательность байтов.
  * байт — число от 0 до 255; обращение к строке по индексу (digits[3])
  возвращает именно байт, а не строку.
  * руна — код одного символа Unicode (тип rune, он же int32); здесь руны не
  нужны, потому что все цифры и буквы A-F помещаются в один байт.
  * string(digits[rest]) — преобразование одного байта в строку из одного
  символа.
  * % — остаток от деления; для отрицательного левого операнда результат
  отрицательный.
  * / — для целых чисел деление нацело, дробная часть отбрасывается.
  * bool — тип с двумя значениями true и false.
  * := — объявление переменной с автоматическим выводом типа из значения
  справа.
  * + для строк — конкатенация, склейка двух строк в новую.
  * for условие { } — цикл, повторяющийся пока условие истинно (аналог
  while).
  * return — выход из функции с возвратом значения.

------------------------------------------------------------------------------
  ЧТО ПРОСЯТ СДЕЛАТЬ
------------------------------------------------------------------------------
  Написать программу, которая принимает любое количество аргументов-опций и
  печатает их представление в виде групп бит с переводом строки в конце.
  Опция — аргумент, начинающийся с дефиса, дальше идут буквы из набора a-z.
  Все опции хранятся в одном int: каждая буква — один бит, a это самый
  правый (младший) бит, z — двадцать шестой. Печатается всё 32-битное число:
  четыре группы по восемь бит, разделённые пробелами. Если аргументов нет
  вообще или в каком-то из аргументов флаг -h стоит первым символом после
  дефиса — печатается строка со списком всех допустимых опций. Неправильная
  опция — печатается Invalid Option и перевод строки.


------------------------------------------------------------------------------
  КАК ДУМАТЬ НАД ЗАДАЧЕЙ (читать до кода)
------------------------------------------------------------------------------
  Задача распадается на три независимые части: как хранить опции, как их
  печатать и как разбирать аргументы. Хранение: условие прямо рисует схему
  ******zy xwvutsrq ponmlkji hgfedcba — это одно 32-битное число, где буква
  a занимает самый правый бит (номер 0), b — бит 1, и так до z — бит 25;
  верхние шесть бит не используются и всегда нули. Значит номер бита для
  буквы вычисляется вычитанием: c - 'a' даёт 0 для 'a' и 25 для 'z', потому
  что буквы в таблице символов идут подряд. Включить бит номер n в числе —
  это операция flags = flags | 1<<n: 1<<n это единица, сдвинутая влево на n
  позиций, а | (побитовое ИЛИ) ставит эту единицу в нужное место, не трогая
  остальные биты. Повторное включение того же бита ничего не портит, поэтому
  -eeeeee даёт то же самое, что -e. Печать: надо вывести все 32 бита,
  начиная со старшего, поэтому цикл идёт от i = 31 вниз до 0; проверка
  отдельного бита — flags & (1<<i) != 0, где & (побитовое И) обнуляет все
  биты кроме проверяемого. Пробел ставится после каждой группы из восьми
  бит, кроме последней: номера бит, на которых группа заканчивается — 24,
  16, 8 и 0, то есть i % 8 == 0, и из них исключается i == 0, чтобы не было
  лишнего пробела перед переводом строки. Разбор аргументов: идём слева
  направо. Аргумент годится, только если он длиной хотя бы два символа и
  начинается с дефиса — поэтому одиночный дефис это Invalid Option. Флаг -h
  проверяется отдельно и только на позиции 1, то есть сразу после дефиса:
  условие говорит, что приоритет у -h только когда он вызван первым в одном
  из аргументов, и пример -zh это подтверждает — там h пошёл обычным битом.
  Все остальные символы аргумента обязаны попадать в диапазон от 'a' до 'z',
  иначе Invalid Option и немедленный выход. Печатаем биты только после того,
  как все аргументы прошли проверку.

  СВЕРЕНО С ЭТАЛОНОМ ШКОЛЫ: 🔴 Поведение в краевых случаях взято из ЭТАЛОНА
  школы, а не из текста задания — они местами расходятся, а бот сверяет
  ответ именно с эталоном. Обрати внимание, что происходит при отсутствии
  аргументов и при пустом результате: молчание и печать пустой строки — это
  разные вещи, и бот их различает.

    package main
    
    import (
    	"fmt"
    	"os"
    	"unicode"
    )
    
    func main() {
    	if len(os.Args) < 2 {
    		fmt.Println("options: abcdefghijklmnopqrstuvwxyz")
    		return
    	}
    
    	var options [32]bool
    	for _, v := range os.Args {
    		if len(v) < 2 {
    			fmt.Println("Invalid Option")
    			return
    		}
    		if v[0] == '-' {
    			if v[1] == 'h' {
    				fmt.Println("options: abcdefghijklmnopqrstuvwxyz")
    				return
    			}
    			// fill options
    			for _, r := range v[1:] {
    				if !unicode.Is(unicode.Latin, r) {
    					fmt.Println("Invalid Option")
    					return
    				}
    				options['z'-r+6] = true
    			}
    		}
    	}
    	for i, v := range options {
    		if i%8 == 0 && i != 0 {
    			fmt.Print(" ")
    		}
    		if v {
    			fmt.Print(1)
    		} else {
    			fmt.Print(0)
    		}
    	}
    	fmt.Println()
    }

			fmt.Println("Invalid Option")
			return
		}

  Заодно эта проверка защищает строки ниже: без неё обращение к v[1] у односимвольного аргумента уронило бы программу.

  🔴 Аргументы без дефиса (длиной 2 и больше) сюда не заходят и просто игнорируются — никакой ошибки на них не будет.

					fmt.Println("Invalid Option")
					return
				}

  Print(1) без кавычек печатает ЧИСЛО, и fmt выводит его десятичную запись — символ 1. Результат на экране тот же, что и от Print("1").

  ТЕРМИНЫ, КОТОРЫЕ ЗДЕСЬ ВСТРЕТИЛИСЬ
------------------------------------------------------------------------------
  * os.Args — срез строк с аргументами командной строки; os.Args[0] это имя
  программы, поэтому нужные аргументы начинаются с индекса 1.
  * срез (slice) — список значений переменной длины; args[1:] создаёт новый
  срез, начинающийся с элемента 1.
  * []byte — срез байтов, изменяемый аналог строки.
  * байт — целое число от 0 до 255; строка при индексации отдаёт байты, а
  сравнение байтов — это сравнение кодов символов.
  * руна — код символа Unicode (тип rune); здесь не нужна, потому что весь
  ввод — однобайтовые латинские символы.
  * бит — один разряд двоичной записи числа; бит номер 0 самый правый.
  * 1<<n — сдвиг влево: единица, перемещённая на n позиций влево, то есть
  число 2 в степени n.
  * | — побитовое ИЛИ: включает биты, не выключая уже включённые.
  * & — побитовое И: оставляет только те биты, которые есть в обоих числах;
  применяется для проверки одного бита.
  * append(срез, элемент) — добавляет элемент в конец среза и возвращает
  новый срез; результат обязательно присваивается обратно.
  * range — перебор элементов среза; выдаёт индекс и значение.
  * _ — пустое имя переменной, означает "значение не нужно".
  * os.Stdout.WriteString — печать строки в стандартный вывод без пакета
  fmt.
  * return в main — немедленное завершение программы.

------------------------------------------------------------------------------
  ЧТО ПРОСЯТ СДЕЛАТЬ
------------------------------------------------------------------------------
  Написать программу, которая переводит слово, переданное аргументом, в его
  версию на Pig Latin. Правила: если слово начинается с гласной — просто
  дописать в конец "ay"; если с согласной — все согласные до первой гласной
  перенести в конец слова и потом дописать "ay". Гласными считаются только
  латинские aeiou (пример Is → Isay показывает, что заглавные тоже
  считаются). Если в слове нет ни одной гласной — напечатать "No vowels".
  Если аргументов не ровно один — программа не печатает ничего.


------------------------------------------------------------------------------
  КАК ДУМАТЬ НАД ЗАДАЧЕЙ (читать до кода)
------------------------------------------------------------------------------
  Всё решение сводится к одному числу — позиции первой гласной в слове. Если
  её найти, три случая из условия закрываются одной формулой. Идём по слову
  слева направо и запоминаем индекс первого символа, который является
  гласной; как только нашли, останавливаемся. Начальное значение этой
  переменной должно быть -1, а не 0, иначе будет невозможно отличить
  "гласная стоит на позиции 0" от "гласных нет вообще". Если после цикла
  значение так и осталось -1 — гласных нет, печатаем No vowels и выходим.
  Иначе ответ строится склейкой трёх кусков: часть слова начиная с первой
  гласной, потом часть слова до первой гласной, потом "ay". Отдельная ветка
  для слова, начинающегося с гласной, не нужна: если первая гласная стоит на
  позиции 0, то кусок "до неё" пустой, и формула сама даёт слово плюс ay —
  ровно то, что требует первое правило. Проверку на гласную выносим в
  маленькую функцию со switch: перечислять десять вариантов через || в одном
  условии длиннее и легче ошибиться. Заглавные гласные обязаны попасть в
  список: пример Is → Isay работает только если 'I' признана гласной.
  Аргументы берём из os.Args[1:]; если их количество не равно единице, надо
  выйти молча, вообще ничего не печатая — даже пустой строки. Работа идёт с
  байтами, а не с рунами, потому что все проверяемые символы однобайтовые, а
  срез строки по индексу гласной никогда не разрежет многобайтовый символ
  пополам: у байтов внутри многобайтовых символов коды выше, чем у любой
  латинской буквы.

  СВЕРЕНО С ЭТАЛОНОМ ШКОЛЫ: 🔴 Поведение в краевых случаях взято из ЭТАЛОНА
  школы, а не из текста задания — они местами расходятся, а бот сверяет
  ответ именно с эталоном. Обрати внимание, что происходит при отсутствии
  аргументов и при пустом результате: молчание и печать пустой строки — это
  разные вещи, и бот их различает.

package main
  Исполняемая программа: пакет main плюс функция main.

import (
	"fmt"
	"os"
	"strings"
)
  fmt — печать. os — аргументы командной строки. strings — из него нужна одна функция, IndexAny.
  Раз эталон школы их использует — для этого задания все три пакета разрешены.

func main() {
  Точка входа. Вспомогательных функций в задании нет, вся логика здесь.

	if len(os.Args) != 2 || os.Args[1] == "" {
  Два условия через || («или»): достаточно, чтобы сработало любое.
  len(os.Args) != 2 — os.Args[0] это имя программы, значит ровно один настоящий аргумент даёт длину 2. Всё, что не 2, отсеивается.
  os.Args[1] == "" — аргумент передали, но он пустой.
  🔴 Порядок частей здесь обязателен. || вычисляет левую часть первой и, если она истинна, правую вообще не трогает (короткое замыкание). Поменяешь местами — при запуске без аргументов программа сначала полезет в os.Args[1], которого нет, и упадёт с ошибкой выхода за границу.

		return
  Ранний выход: программа заканчивается, не напечатав ничего.
  🔴 Ничего — это именно ничего, а не пустая строка. fmt.Println("") вывел бы \n и ответ не совпал бы с эталоном.

	}
	s := os.Args[1]
  Кладём аргумент в короткую переменную. := создаёт новую переменную и сразу присваивает значение; тип string Go выводит сам.
  Обращение к os.Args[1] безопасно, потому что проверка выше уже отсекла случай, когда аргумента нет.

	vowel := strings.IndexAny(s, "aeiouAEIOU")
  IndexAny ищет ПЕРВОЕ вхождение любого символа из второго аргумента и возвращает его байтовый индекс. Если не нашлось ни одного — возвращает -1.
  Второй аргумент — набор гласных: сначала строчные aeiou, затем заглавные AEIOU. Заглавные включены потому, что по условию Is превращается в Isay, то есть большая I тоже считается гласной.
  🔴 y в наборе нет — по условию гласными считаются только aeiou.
  Одним вызовом решаются сразу обе задачи: найти границу согласных и понять, есть ли гласные вообще.

	if vowel == -1 {
  -1 — это условное «не найдено». Такое соглашение у всех функций Index* в пакете strings: индекс не может быть отрицательным, поэтому -1 занято под «нет совпадения».

		fmt.Println("No vowels")
  Печатаем требуемое сообщение. Println сам добавляет перевод строки в конце.
  🔴 Текст точный: No с большой буквы, vowels с маленькой, между ними один пробел.

	} else {
  Ветка «гласная найдена, vowel — её индекс».

		fmt.Println(string(s[vowel:]) + string(s[:vowel]) + "ay")
  Разбираем по частям.
  s[vowel:] — срез строки от индекса гласной до конца: слово начиная с первой гласной. Левая граница включается.
  s[:vowel] — срез от начала до индекса гласной НЕ включая: все согласные перед первой гласной. Правая граница в Go никогда не включается — поэтому сама гласная сюда не попадает и не дублируется.
  string(...) — преобразование к строке. Срез строки уже строка, так что эти преобразования ничего не меняют; они есть в эталоне школы, пиши как есть.
  Знак + склеивает строки. Порядок частей и есть правило Pig Latin: сначала кусок с первой гласной, потом перенесённые согласные, потом "ay".
  🔴 Случай «слово начинается с гласной» отдельно НЕ обрабатывается — он получается сам. При vowel == 0 срез s[:0] пустой, склейка даёт всё слово плюс "ay". Отдельная ветка if для этого не нужна.
  Println добавляет перевод строки — вывод обязан им заканчиваться.

	}
}
  Закрываются else и функция main.

ПРОВЕРЬ СЕБЯ НА ПРИМЕРАХ
  "apple" → vowel = 0 → "apple" + "" + "ay" = appleay.
  "chair" → vowel = 2 → "air" + "ch" + "ay" = airchay.
  "Is" → vowel = 0, потому что I есть в наборе заглавных → Isay.

  Написать программу rn, которая переводит число, переданное аргументом, в
  римскую запись и печатает две строки: сначала разложение-вычисление
  (слагаемые через плюс, вычитательные пары в скобках, например (M-C)),
  затем само римское число. Предел — 4000: само 4000 уже недопустимо. При
  недопустимом значении (буквы вроде hello, ноль, 4000 и больше) печатается
  строка ERROR: cannot convert to roman digit.


------------------------------------------------------------------------------
  КАК ДУМАТЬ НАД ЗАДАЧЕЙ (читать до кода)
------------------------------------------------------------------------------
  Задача состоит из двух независимых частей: превратить строку в число и
  превратить число в римскую запись. Первая часть — разбор строки вручную:
  идём по символам, каждый обязан быть цифрой от '0' до '9', иначе сразу
  возвращаем признак ошибки; само число накапливаем формулой n = n*10 +
  значение цифры, где значение получается вычитанием s[i]-'0', потому что
  цифры в таблице символов идут подряд. Здесь нужна страховка от
  переполнения: если аргумент длинный, например двадцать девяток, накопление
  выйдет за пределы int и число может стать отрицательным, то есть мусор
  пройдёт проверку. Поэтому как только накопленное превысило 4000, дальше
  считать бессмысленно — ответ в любом случае ошибка, возвращаем 4000 и на
  этом останавливаемся. Функция возвращает два значения: число и
  bool-признак успеха; это стандартный приём в Go, когда нужно сообщить не
  только результат, но и получилось ли. Вторая часть — жадный алгоритм.
  Ключевая идея: римская система становится обычной, если считать
  вычитательные пары CM, CD, XC, XL, IX, IV отдельными «цифрами» со
  значениями 900, 400, 90, 40, 9, 4. Тогда достаточно завести таблицу всех
  тринадцати значений строго по убыванию и рядом с ней таблицу их
  обозначений; идём по таблице сверху вниз и, пока текущее значение
  помещается в остаток числа, отнимаем его и приписываем символ. Порядок по
  убыванию гарантирует, что 9 будет записано как IX, а не как VIIII, потому
  что 9 встретится в таблице раньше, чем 5. Строка с вычислением строится по
  той же таблице, но с третьим массивом, где вычитательные пары записаны в
  скобках; плюс ставится перед каждым элементом, кроме самого первого —
  проверка «строка ещё пустая» это и определяет. В конце печатаются две
  отдельные строки, каждая со своим переводом строки.

    package main
    
    import (
    	"fmt"
    	"os"
    	"strconv"
    	"strings"
    )
    
    type roman struct {
    	num        int
    	romanDigit string
    }
    
    func main() {
    	if len(os.Args) == 2 {
    		nbr, err := strconv.Atoi(os.Args[1])
    		if err != nil || nbr >= 4000 || nbr == 0 {
    			fmt.Println("ERROR: cannot convert to roman digit")
    			return
    		}
    		patter := []roman{
    			{num: 1000, romanDigit: "M"},
    			{num: 900, romanDigit: "CM"},
    			{num: 500, romanDigit: "D"},
    			{num: 400, romanDigit: "CD"},
    			{num: 100, romanDigit: "C"},
    			{num: 90, romanDigit: "XC"},
    			{num: 50, romanDigit: "L"},
    			{num: 40, romanDigit: "XL"},
    			{num: 10, romanDigit: "X"},
    			{num: 9, romanDigit: "IX"},
    			{num: 5, romanDigit: "V"},
    			{num: 4, romanDigit: "IV"},
    			{num: 1, romanDigit: "I"},
    		}
    		sumRoman, romandigit := print(nbr, patter)
    		fmt.Println(strings.TrimSuffix(sumRoman, "+"))
    		fmt.Println(romandigit)
    	}
    }
    
    func print(nbr int, patter []roman) (string, string) {
    	var sumRomanDigit, result string
    	for _, v := range patter {
    		for nbr >= v.num {
    			sumRomanDigit += v.romanDigit + "+"
    			result += v.romanDigit
    			nbr -= v.num
    		}
    	}
    	sumRomanDigit = formatsum(sumRomanDigit, patter)
    	return sumRomanDigit, result
    }
    
    func formatsum(a string, patter []roman) string {
    	result2 := strings.Split(a, "+")
    
    	for i, v := range result2 {
    		if len(v) == 2 {
    			result2[i] = fmt.Sprintf("(%s-%s)", string(result2[i][1]), string(result2[i][0]))
    		}
    	}
    	a = strings.Join(result2, "+")
    	return a
    }

  `+=` для строк — дописать справа. К накопителю добавляется римский кусок и плюс.
  🔴 Плюс добавляется после **каждого** куска, включая последний. Поэтому в конце всегда висит лишний `+` — его снимет `TrimSuffix` в `main`.

```go
			result += v.romanDigit
```
  Второй накопитель — то же самое, но без плюсов. Это и будет готовое римское число.

```go
			nbr -= v.num
```
  Уменьшаем остаток. `nbr -= v.num` это то же, что `nbr = nbr - v.num`.
  🔴 Без этой строки внутренний цикл никогда не закончится — условие останется верным навсегда.
  🔴 `nbr` — копия параметра. Изменение здесь не трогает переменную `nbr` в `main`.

```go
		}
	}
	sumRomanDigit = formatsum(sumRomanDigit, patter)
```
  Здесь `=`, а не `:=`: переменная `sumRomanDigit` уже объявлена выше, создавать её заново нельзя.

```go
	return sumRomanDigit, result
}
```
  Возврат двух значений через запятую, в том же порядке, что объявлен в `(string, string)`.

```go
func formatsum(a string, patter []roman) string {
```
  🔴 Второй параметр `patter` в теле не используется ни разу. В Go неиспользуемый **параметр** разрешён, а неиспользуемая **локальная переменная** — ошибка компиляции. Это разные правила, их часто путают.

```go
	result2 := strings.Split(a, "+")
```
  `Split` режет строку по разделителю и отдаёт срез кусков. Из `"M+CM+XC+"` получится `["M", "CM", "XC", ""]`.
  🔴 Последний кусок — **пустая строка**. Так работает `Split`: строка кончается разделителем, значит после него есть пустой кусок. Это не баг, а ожидаемое поведение.

```go
	for i, v := range result2 {
```
  Здесь нужен и номер `i`, и значение `v` — потому что дальше в срез будут записывать по номеру.

```go
		if len(v) == 2 {
```
  🔴 Хитрость: длина куска однозначно отличает вычитательную пару от простой буквы. Простые буквы `M D C L X V I` — 1 символ. Пары `CM CD XC XL IX IV` — ровно 2. Пустой хвостовой кусок — 0. Никаких дополнительных проверок не нужно.

```go
			result2[i] = fmt.Sprintf("(%s-%s)", string(result2[i][1]), string(result2[i][0]))
```
  `Sprintf` собирает строку по шаблону и **возвращает** её (в отличие от `Printf`, которая печатает). `%s` — место, куда подставится строка.
  `result2[i][1]` — обращение к строке по номеру даёт один **байт** (число). `string(...)` превращает этот байт обратно в строку из одного символа.
  🔴 Порядок переставлен намеренно: сначала берётся символ с номером **1** (второй), потом с номером **0** (первый). Для `"CM"` выходит `"(M-C)"` — 900 это тысяча минус сто. Поменяешь местами — получишь `(C-M)`, что неверно.
  🔴 Запись идёт в `result2[i]`, а не в `v`. `v` — копия, изменение копии в срез не попадёт.

```go
		}
	}
	a = strings.Join(result2, "+")
```
  `Join` — обратная операция к `Split`: склеивает куски, вставляя разделитель **между** ними. Пустой хвостовой кусок при этом снова даёт плюс в конце.

```go
	return a
}
```
  Возврат готовой строки разложения.

------------------------------------------------------------------------------
  ТЕРМИНЫ, КОТОРЫЕ ЗДЕСЬ ВСТРЕТИЛИСЬ
------------------------------------------------------------------------------
  * os.Args — срез строк с аргументами командной строки.
  * срез (slice) — список значений переменной длины; []int{...} и
  []string{...} создают срез сразу с содержимым.
  * параллельные срезы — два или три среза одинаковой длины, где элементы с
  одним индексом относятся к одному и тому же понятию.
  * функция с двумя результатами — (int, bool): второй результат сообщает,
  получилось ли; принимается записью n, ok := f().
  * bool — тип с двумя значениями true и false.
  * ! — логическое НЕ; !ok означает "не получилось".
  * byte — символ строки при индексации; s[i]-'0' переводит символ-цифру в
  её числовое значение.
  * int(...) — приведение типа, здесь из byte в int.
  * жадный алгоритм — на каждом шаге берётся самое большое подходящее
  значение; для римских чисел с полной таблицей он всегда даёт правильный
  ответ.
  * переполнение — выход результата за пределы диапазона int; проявляется
  как внезапно отрицательное или маленькое число.
  * конкатенация — склейка строк оператором +.
  * вложенный цикл — цикл внутри цикла; внешний идёт по таблице, внутренний
  повторяет одно значение нужное число раз.


------------------------------------------------------------------------------
  ГДЕ ЗАВАЛИВАЮТСЯ НА ЭТОЙ ЗАДАЧЕ
------------------------------------------------------------------------------
  * Предел 4000 означает, что само 4000 уже ошибка: допустимый диапазон
  1..3999.
  * Ноль — ошибка, это прямо указано в условии.
  * Забыть в таблице пары 900, 400, 90, 40, 9, 4 — тогда 999 выйдет как
  DCCCCLXXXXVIIII вместо CMXCIX.
  * Таблица обязана быть строго по убыванию, иначе жадный алгоритм соберёт
  неправильную запись.
  * Плюс не должен появляться в начале первой строки; проверка expr != ""
  именно для этого.
  * Скобки ставятся только у вычитательных пар, у обычных символов их нет.
  * Вывод — ДВЕ строки, каждая со своим \n: сначала вычисление, потом само
  число.
  * Забыть n = n - values[i] внутри цикла — программа зависнет.
  * Разбирать число через strconv без проверки диапазона: очень длинный
  аргумент переполнит int и мусор может пройти как валидное число. Обрезка
  при n > 4000 это закрывает.
  * Минус в аргументе (-5) — не цифра, значит ошибка; отдельной обработки
  отрицательных не требуется.
  * Ведущие нули допустимы: 012 читается как 12 и даёт XII.
  * Додумать поведение для случая «аргументов нет» по логике. Проверь
  эталон: иногда там молчание, иногда пустая строка.
