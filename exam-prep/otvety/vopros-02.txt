------------------------------------------------------------------------------

------------------------------------------------------------------------------
  Написать функцию, которая получает строку и возвращает true, если внутри
  строки есть хотя бы одна цифра. Если цифр нет — вернуть false. Ничего
  печатать не надо, функция только возвращает логическое значение. В примере
  "Hello" даёт false, а "Hello1" — true.


------------------------------------------------------------------------------
  ПРОТОТИП — переписывать БУКВА В БУКВУ
------------------------------------------------------------------------------
    func CheckNumber(arg string) bool {
    }

  Бот школы сверяет подпись функции посимвольно. Другое имя, другой порядок
  или тип параметров, лишний или недостающий возврат — задача не засчитана.


------------------------------------------------------------------------------
  КАК ДУМАТЬ НАД ЗАДАЧЕЙ (читать до кода)
------------------------------------------------------------------------------
  Дано: одна строка. Надо: ответ да/нет. Вопрос «есть ли хотя бы один такой
  символ» всегда решается одним проходом по строке с досрочным выходом.
  Нужно уметь ответить на вопрос «этот конкретный символ — цифра?». В Go
  символ можно сравнивать напрямую, потому что за каждым символом стоит его
  числовой код, а коды цифр от '0' до '9' идут подряд без пропусков. Значит
  проверка «код символа не меньше кода '0' и не больше кода '9'» ловит ровно
  цифры и никого больше. Дальше логика простая: как только нашли цифру,
  продолжать смысла нет — сразу возвращаем true. Если цикл дошёл до конца и
  ни разу не сработал возврат, значит цифр не было — возвращаем false.
  Порядок важен: false должен стоять ПОСЛЕ цикла, а не внутри него, иначе
  функция сдастся на первой же букве. Пустая строка обрабатывается сама
  собой: цикл не сделает ни одного шага и вернётся false.


------------------------------------------------------------------------------
  ГОТОВОЕ РЕШЕНИЕ
------------------------------------------------------------------------------
    package piscine
    
    func CheckNumber(str string) bool {
    	for _, c := range str {
    		if c >= '0' && c <= '9' {
    			return true
    		}
    	}
    	return false
    }

package piscine
  Библиотека. Импортов нет вообще — ничего постороннего не нужно, и это принципиально: неиспользуемый импорт в Go не компилируется.

func CheckNumber(str string) bool {
  Принимает строку, возвращает bool — логическое значение, true или false. Печати внутри нет и быть не должно.

	for _, c := range str {
  range по строке выдаёт две вещи: индекс байта и руну (руна = один символ, точнее его код).
  _ выбрасывает индекс — он в этой задаче не нужен. c — очередной символ строки.

		if c >= '0' && c <= '9' {
  Одинарные кавычки — это руна, то есть код символа: '0' это 48, '9' это 57.
  В таблице символов десять цифр идут подряд, поэтому вместо десяти сравнений хватает проверки диапазона.
  && — «и», обе части должны быть верны одновременно.
  🔴 Сравнивать надо именно с '0' в кавычках, а не с числом 0. Условие c >= 0 верно вообще всегда, функция начнёт возвращать true на любой непустой строке.
  🔴 Кавычки именно одинарные. "0" в двойных — это строка, с руной она не сравнивается, будет ошибка компиляции.

			return true
		}
	}
  Ранний выход: одна цифра найдена — ответ уже известен, остаток строки смотреть незачем.

	return false
}
  Сюда управление приходит, только если цикл прошёл всю строку и ни разу не вернул true.
  🔴 Эта строка ОБЯЗАНА стоять после цикла, а не внутри него. Если засунуть её в else внутри цикла, функция вернёт false на первом же не-цифре, и "Hello1" даст false.
  🔴 Пустая строка: цикл не делает ни одного витка, управление сразу приходит сюда — false. Так и требуется.
  Без этой строки код не соберётся: у функции с типом результата на каждом пути выполнения должен быть return.

  * string (строка) — последовательность символов, например "Hello1"
  * bool (логический тип) — тип с двумя возможными значениями: true (истина)

  * range — форма цикла for, которая сама проходит по всем элементам строки
  или списка
  * _ (подчёркивание) — имя-пустышка: сюда кладут значение, которое не
  собираются использовать
  * return — команда немедленно закончить работу функции и отдать указанное
  значение
  * && — логическое «и»: результат истинен, только если истинны оба условия
  * package piscine — объявление, что файл принадлежит пакету piscine;
  обязательная первая строка во всех заданиях-функциях

  ГДЕ ЗАВАЛИВАЮТСЯ НА ЭТОЙ ЗАДАЧЕ
------------------------------------------------------------------------------
  * Сравнивать с числами без кавычек: r >= 0 && r <= 9 скомпилируется, но
  проверит служебные коды 0-9, а не символы цифр. Кавычки обязательны.
  * Поставить return false внутрь цикла (в ветку else). Тогда "Hello1"
  вернёт false, потому что функция сдастся на первой букве H. false ставится
  строго после цикла.
  * Забыть return false в конце — ошибка компиляции missing return.
  * Условие «содержит число» здесь означает именно цифры от 0 до 9. Минус,

  * Пустая строка отдельной проверки не требует: цикл не сделает ни шага,

  знаки препинания не считаются. По примерам: "Hello world" даёт 10 (пробел

    }

  Бот школы сверяет подпись функции посимвольно. Другое имя, другой порядок
  или тип параметров, лишний или недостающий возврат — задача не засчитана.


------------------------------------------------------------------------------
  КАК ДУМАТЬ НАД ЗАДАЧЕЙ (читать до кода)
------------------------------------------------------------------------------
  Дано: строка. Надо: одно число — сколько в ней букв. Задача типа
  «посчитать сколько элементов подходят под условие», а такие задачи всегда
  решаются одинаково: заводим счётчик, равный нулю, проходим по всем
  элементам, и на каждом подходящем прибавляем единицу. В конце возвращаем
  счётчик. Единственное, что надо решить отдельно — как проверить «это
  буква». Коды латинских букв идут двумя непрерывными кусками: сначала все
  заглавные от 'A' до 'Z', потом чуть дальше все строчные от 'a' до 'z'.
  Между этими кусками лежат посторонние символы, поэтому одним сравнением от
  'A' до 'z' обойтись нельзя — туда попадут скобки и подчёркивание. Значит
  нужны две проверки, объединённые словом «или»: символ либо в диапазоне
  строчных, либо в диапазоне заглавных. Примеры из задания подтверждают
  трактовку: в "H1e2l3l4o" цифры не посчитаны, в "Hello world" пробел не
  посчитан. Пустая строка обрабатывается сама: цикл не сделает шагов,
  счётчик останется нулём.


------------------------------------------------------------------------------
  ГОТОВОЕ РЕШЕНИЕ
------------------------------------------------------------------------------
    package piscine
    
    func CountAlpha(s string) int {
    	count := 0
    	for _, c := range s {
    		if c >= 'a' && c <= 'z' || c >= 'A' && c <= 'Z' {
    			count++
    		}
    	}
    	return count
    }

РАЗБОР ПО СТРОКАМ — CountAlpha

package piscine
  Имя пакета. Задание — функция, значит пакет учебный, main нет.
  🔴 Импортов нет вообще. Всё решается сравнением кодов символов, пакет unicode не
  нужен. Подключишь неиспользуемый пакет — файл не скомпилируется: в Go лишний импорт
  это ошибка, а не предупреждение.

func CountAlpha(s string) int {
  Объявление функции. Имя с большой буквы — чтобы функцию было видно снаружи пакета.
  Один параметр s типа string. После скобок int — тип результата: возвращается целое
  число.

	count := 0
  Создаём накопитель-счётчик и кладём в него 0. Знак := создаёт НОВУЮ переменную и
  сразу задаёт значение; тип int Go выводит из нуля.
  🔴 Счётчик объявлен ДО цикла. Объявишь внутри — он будет обнуляться на каждом витке,
  и функция вернёт 0 или 1.

	for _, c := range s {
  Цикл по символам строки. range по строке даёт два значения: номер байта, с которого
  символ начинается, и сам символ как руну (руна — один символ целиком, хранится как
  число-код).
  _ (подчёркивание) выбрасывает номер: он в задаче не нужен, а неиспользуемая
  переменная в Go — ошибка компиляции, поэтому подчёркивание обязательно.
  c — очередной символ.
  🔴 range сам доходит до конца строки, поэтому ни len, ни ручного счётчика тут нет и
  выйти за границы невозможно.

		if c >= 'a' && c <= 'z' || c >= 'A' && c <= 'Z' {
  Проверка «этот символ — латинская буква».
  Записи 'a', 'z', 'A', 'Z' в одинарных кавычках — это ЧИСЛА, коды символов
  (97, 122, 65, 90). Буквы в таблице кодов идут подряд, поэтому «код попал между 'a'
  и 'z'» в точности означает «это строчная латинская буква». Второй диапазон — то же
  для заглавных.
  && это «и» (обе части должны быть истинны), || это «или» (достаточно одной части).

  🔴 ПРИОРИТЕТ ОПЕРАТОРОВ. Скобок в условии нет, и они не нужны: в Go && связывает
  сильнее, чем ||. Компилятор читает эту строку как
  (c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z') — сначала группируются пары с &&,
  потом они соединяются через ||. Если сомневаешься на экзамене — поставь скобки явно,
  смысл не изменится, а читать будет проще.

  🔴 Проверять надо ОБА диапазона. Забудешь заглавные — "Hello world" даст 9 вместо 10.
  Пробелы, цифры и знаки препинания не попадают ни в один диапазон и не считаются —
  отдельного условия для них писать не нужно.

			count++
  Увеличиваем счётчик на единицу. count++ — короткая запись для count = count + 1.
  🔴 В Go ++ это отдельный ОПЕРАТОР, а не выражение: писать x := count++ или
  ++count нельзя, компилятор откажет. Только отдельной строкой.

		}
  Конец if. Если символ не буква, тело просто пропускается и цикл идёт дальше.

	}
  Конец цикла.

	return count
  Возвращаем итог. return стоит ПОСЛЕ цикла — поставишь внутрь, функция оборвётся на
  первом же символе и вернёт 0 или 1.

	}
  Конец функции.

ПРОВЕРКА НА ПРИМЕРАХ ИЗ УСЛОВИЯ
  "Hello world" — 11 символов, из них пробел не буква → 10.
  "H e l l o"   — 5 букв и 4 пробела → 5.
  "H1e2l3l4o"   — 5 букв и 4 цифры → 5.

ЛОВУШКИ ЗАДАНИЯ
  🔴 Считаются только латинские a-z и A-Z. Кириллица, цифры, пробелы, знаки — нет.
  🔴 Возвращается число (int), а не строка. Печатать результат в тестовой программе
     надо через fmt.Println(...) — он сам умеет печатать числа.
  🔴 Пустая строка: цикл не сделает ни витка, вернётся 0. Отдельная проверка на
     пустоту не нужна.
  🔴 Эталон идёт по рунам через range, а не по байтам через s[i]. Для чистой латиницы
     ответ одинаков, но range безопаснее: он никогда не разрежет символ пополам.


------------------------------------------------------------------------------
  ТЕРМИНЫ, КОТОРЫЕ ЗДЕСЬ ВСТРЕТИЛИСЬ
------------------------------------------------------------------------------
  * int — тип целого числа (без дробной части), может быть отрицательным
  * счётчик — обычная переменная, в которой копят количество; всегда
  начинается с нуля
  * count++ — увеличить значение переменной count на единицу
  * || — логическое «или»: результат истинен, если истинно хотя бы одно из
  условий
  * && — логическое «и»: результат истинен, только если истинны оба условия
  * rune (руна) — числовой код одного символа; 'a' в одинарных кавычках это
  руна, а не строка
  * range — форма цикла for, проходящая по всем символам строки
  * string (строка) — последовательность символов
  * диапазон кодов — приём сравнения символа с границами: если код между 'a'
  и 'z', значит символ строчная буква


------------------------------------------------------------------------------
  ГДЕ ЗАВАЛИВАЮТСЯ НА ЭТОЙ ЗАДАЧЕ
------------------------------------------------------------------------------

  * Проверить только строчные буквы — тогда 'H' и 'W' потеряются.

  * Поставить return count внутрь цикла — функция вернёт результат после
  первого же символа.
  * Пустая строка даёт 0 сама по себе, отдельная проверка не нужна.

  буква 'l' встречается 3 раза, в "   " пробел 3 раза, в "The 7 deadly sins"

------------------------------------------------------------------------------
  ПРОТОТИП — переписывать БУКВА В БУКВУ
------------------------------------------------------------------------------
    func CountChar(str string, c rune) int {
        ...
    }

  Бот школы сверяет подпись функции посимвольно. Другое имя, другой порядок
  или тип параметров, лишний или недостающий возврат — задача не засчитана.


------------------------------------------------------------------------------
  КАК ДУМАТЬ НАД ЗАДАЧЕЙ (читать до кода)
------------------------------------------------------------------------------
  Дано: строка и искомый символ. Надо: одно число. Это снова задача
  «посчитать сколько элементов подходят», значит схема та же: счётчик с
  нуля, проход по всем символам, прибавление единицы при совпадении. Отличие
  от countalpha только в условии: вместо проверки диапазона здесь простое
  равенство текущего символа искомому. Важно обратить внимание на типы:
  второй параметр объявлен как rune, поэтому проходить по строке надо тоже
  рунами — через for range. Если брать символы через str[i], получатся
  байты, а байт с руной Go напрямую сравнивать не даст. Оба требования из
  условия — «нет такого символа» и «пустая строка» — выполняются
  автоматически: в первом случае if ни разу не сработает, во втором цикл не
  сделает ни шага, и в обоих вернётся начальный ноль. Отдельных проверок
  писать не надо. В примере из README вызов CountChar("5  balloons", 5) даёт
  0, потому что 5 без кавычек — это число пять, руна со служебным кодом 5, а
  не символ пятёрки.


------------------------------------------------------------------------------
  ГОТОВОЕ РЕШЕНИЕ
------------------------------------------------------------------------------
    package piscine
    
    func CountChar(str string, c rune) int {
    	count := 0
    	for _, r := range str {
    		if r == c {
    			count++
    		}
    	}
    	return count
    }

## РАЗБОР ПО СТРОКАМ

```go
package piscine
```
  Пакет `piscine` — так требуют все задания-функции школы. Файла с `main` здесь нет, сам по себе он не запускается: рядом кладут проверяющую программу, которая вызывает функцию отсюда.

```go
func CountChar(str string, c rune) int {
```
  Объявление функции. Два параметра: `str` типа `string` (строка) и `c` типа `rune` (один символ). Возвращает `int` — целое число.
  🔴 **Руна** — это один символ целиком, независимо от того, сколько байт он занимает. Под капотом `rune` это просто `int32`, то есть номер символа в таблице Unicode. Латинская буква занимает 1 байт, русская 2, эмодзи 4 — как руна каждая из них одна.
  🔴 Типы параметров пишутся отдельно у каждого, потому что они разные. Сократить до `(str, c string)` нельзя — это были бы две строки.

```go
	count := 0
```
  **Накопитель** — переменная, в которой копится ответ. Начинается с нуля.
  `:=` создаёт новую переменную и сразу кладёт в неё значение. Тип `int` Go выводит сам из `0`, писать `var count int = 0` не нужно.
  🔴 Именно эта нулевая начальная величина закрывает сразу два случая из условия: пустая строка и символ, которого в строке нет. Никаких отдельных проверок для них не требуется.

```go
	for _, r := range str {
```
  🔴 Ключевая строка. `range` **по строке** выдаёт две вещи: номер начального байта символа и сам символ как **руну**. Не байт, а именно руну — Go разбирает UTF-8 за тебя.
  `_` — знак «этот результат мне не нужен, выброси». Номер байта здесь не используется.
  🔴 Сравни с `for i := 0; i < len(str); i++ { str[i] ... }` — там `str[i]` даёт **байт**, и русская буква развалилась бы на два куска, ни один из которых не равен искомой руне. Поэтому здесь нужен именно `range`.

```go
		if r == c {
```
  Сравнение двух рун. Обе одного типа `rune`, сравниваются как числа — по номеру символа в Unicode.
  🔴 Сравнение чувствительно к регистру: `'l'` и `'L'` — разные руны. В `"Hello World"` строчных `l` три, прописная `L` не встречается вовсе.

```go
			count++
```
  Увеличить на 1. То же, что `count = count + 1`.
  🔴 В Go `++` это отдельная инструкция, а не выражение. Написать `x := count++` нельзя, и `++count` тоже не существует.

```go
		}
	}
	return count
}
```
  Цикл закончился, когда прошли всю строку. Возвращаем накопленное.
  🔴 `return` стоит **вне** цикла. Если задвинуть его внутрь, функция вышла бы после первого же символа.

### Проверь себя
- `CountChar("Hello World", 'l')` → 3
- `CountChar("   ", ' ')` → 3 (пробел — обычный символ, ищется так же)
- `CountChar("The 7 deadly sins", '7')` → 1 (цифра как символ, руна `'7'`, не число 7)
- `CountChar("", 'a')` → 0 (цикл ни разу не выполнился)
- `CountChar("abc", 'z')` → 0

  ГДЕ ЗАВАЛИВАЮТСЯ НА ЭТОЙ ЗАДАЧЕ
------------------------------------------------------------------------------
  * Считать, что CountChar("5  balloons", 5) должно вернуть 1. Нет: 5 без

  * Пробел — обычный символ: ' ' в одинарных кавычках. В "   " его три

package piscine
  Имя пакета для заданий-функций. Импортов нет вообще — ни fmt, ни strings
  тут не нужны, и это принципиально: функция ничего не печатает, она только
  ВОЗВРАЩАЕТ текст, а печатает его уже тестовая программа.

func PrintIf(arg string) string {
  Функция принимает строку и возвращает строку.
  🔴 В условии параметр назывался str, в эталоне он назван arg — имя параметра
  ни на что не влияет, тест находит функцию по имени PrintIf.
  🔴 Название PrintIf сбивает с толку: слово Print в имени есть, а печати нет.
  Тип возвращаемого значения string прямо говорит: надо вернуть, а не напечатать.

	if len(arg) != 0 && len(arg) < 3 {
  Одно условие из двух частей, соединённых && (логическое И) — истинно, только
  когда истинны обе.
  len(arg) — длина строки в БАЙТАХ.
  len(arg) != 0 — строка не пустая.
  len(arg) < 3 — строка короче трёх символов, то есть в ней 1 или 2 символа.
  🔴 Здесь вся хитрость задания. По условию "G" возвращается при длине от 3 и выше
  И ОТДЕЛЬНО для пустой строки. Прямо это записать сложнее, поэтому эталон
  переворачивает логику: описывает ровно тот узкий случай, когда ответ
  "Invalid Input" — длина 1 или 2 — а всё остальное отправляет в "G".
  Первая часть != 0 существует ровно затем, чтобы вытащить пустую строку
  из-под второй проверки: у пустой строки длина 0, и 0 < 3, так что без первой
  части она ошибочно попала бы в "Invalid Input".
  && ленивое: если первая часть ложна (строка пустая), вторая не вычисляется.

		return "Invalid Input\n"
  Возврат текста ошибки. \n — перевод строки, он часть возвращаемого значения.
  🔴 Текст должен совпадать посимвольно: заглавная I в обоих словах, один пробел
  между ними, перевод строки в конце. Лишний пробел или его отсутствие — тест не пройден.
  return сразу выходит из функции, до следующей строки управление не дойдёт.

	}
  Конец проверки. Ветки else нет — она не нужна, потому что return выше
  уже прервал бы функцию.

	return "G\n"
  Сюда попадаем во всех остальных случаях: пустая строка либо длина 3 и больше.
  Одна заглавная буква G и перевод строки.
  🔴 Перевод строки обязателен: "G" и "G\n" — разные ответы.

}
  Конец функции.

    }

------------------------------------------------------------------------------
  КАК ДУМАТЬ НАД ЗАДАЧЕЙ (читать до кода)
------------------------------------------------------------------------------
  Дано: два целых числа. Надо: одно целое число. Здесь два независимых
  требования, и порядок их проверки решает всё. Сначала обрабатываем запрет:
  если ширина отрицательная ИЛИ высота отрицательная, сразу возвращаем -1 и
  дальше не считаем. Это делается первым, потому что для недопустимых данных
  формула вообще не должна применяться. Если проверка пройдена, считаем
  периметр. У прямоугольника четыре стороны: две шириной и две высотой,
  значит периметр равен w + h + w + h, что короче записывается как 2 * (w +
  h). Скобки обязательны: без них 2 * w + h умножит только ширину. Проверяем
  по примерам: 10 и 2 дают 2 * 12 = 24, сходится; 434343 и 898989 дают 2 *
  1333332 = 2666664, сходится; 10 и -2 дают -1, сходится. Отдельно надо
  заметить, что ноль отрицательным не является, поэтому в условии стоит
  строгое «меньше нуля», а не «меньше или равно».


------------------------------------------------------------------------------
  ГОТОВОЕ РЕШЕНИЕ
------------------------------------------------------------------------------
    package piscine
    
    func RectPerimeter(w, h int) int {
    	if (w < 0) || (h < 0) {
    		return -1
    	}
    
    	return 2 * (w + h)
    }

------------------------------------------------------------------------------
УСЛОВИЕ
Функция получает ширину w и высоту h прямоугольника и возвращает периметр — сумму длин всех четырёх сторон. Если хотя бы одно число отрицательное — вернуть -1.

    (w, h int) — два параметра. Запись w, h int — это сокращение: оба одного типа int, поэтому тип пишется один раз в конце, а не w int, h int. Оба варианта рабочие, эталон использует короткий.

    Проверка на отрицательные значения. || — это логическое «ИЛИ»: всё условие истинно, если истинна хотя бы одна из двух частей.

  Дано: строка. Надо: её начальный кусок. В Go кусок строки берут срезом:
  str[a:b] даёт часть строки с позиции a до позиции b, причём символ на
  позиции b в результат НЕ входит. Значит первая половина это
  str[0:половина], а поскольку начало с нуля можно не писать, короче —
  str[:половина]. Остаётся посчитать половину. len(str) даёт длину, и
  деление целых чисел в Go само отбрасывает дробную часть: 11 / 2 даёт 5, а
  не 5.5. Это ровно то округление вниз, которого требует условие, поэтому
  никакой отдельной обработки нечётной длины не нужно. Проверяем по
  примерам: длина 40 даёт 20 символов, длина 11 даёт 5 — сходится. Но
  условие содержит требование, которое из формулы не следует: строка длиной
  1 должна вернуться целиком, а формула даст 1 / 2 = 0, то есть пустую
  строку. Значит этот случай надо выписать отдельно и поставить его ПЕРЕД
  общей формулой. Пустая строка отдельной ветки не требует: 0 / 2 = 0, срез
  str[:0] даёт пустую строку и не приводит к падению.

  сравнивает твой ответ. Значит все пакеты, которые он подключает, для этого
  задания разрешены: будь иначе, проверка не собралась бы.

    package piscine
    
    import "strings"
    
    func RetainFirstHalf(str string) string {
    	if len(str) == 0 {
    		return ""
    	} else if len(str) == 1 {
    		return (str)
    	} else {
    		var res strings.Builder
    		i := 0
    		for i = 0; i < int(len(str)/2); i++ {
    			res.WriteRune(rune(str[i]))
    		}
    		return res.String()
    	}
    }

package piscine
  Пакет piscine. Так помечаются задания-функции: запускать их нельзя, их подключает и вызывает тестовая программа школы.

import "strings"
  Подключается пакет strings. Здесь из него нужна ровно одна вещь — Builder, накопитель строк. Раз пакет использует эталон школы, для этого задания он разрешён.

func RetainFirstHalf(str string) string {
  Объявление функции. Имя ровно такое, как в задании — с большой буквы, иначе тестовая программа её не увидит.
  Один параметр str типа string. После круглых скобок стоит string — это тип возвращаемого значения. Функция ОБЯЗАНА вернуть строку по любому пути выполнения.

	if len(str) == 0 {
  Проверка на пустую строку. len(str) — длина строки в БАЙТАХ, возвращает int. Знак == — сравнение (один знак = был бы присваиванием).

		return ""
  Возвращаем пустую строку. return немедленно заканчивает работу функции — дальше по коду выполнение не идёт.

	} else if len(str) == 1 {
  Иначе — проверка на строку из одного байта. else if читается «а иначе, если».

		return (str)
  Возвращаем саму строку без изменений. Круглые скобки вокруг str ничего не делают, они просто написаны — return str значил бы то же самое.
  🔴 Эта ветка НЕ лишняя. Общая формула ниже взяла бы len/2 = 1/2 = 0 символов и вернула пустую строку, а по условию для строки длиной 1 надо вернуть её саму. Убери ветку — задание не сдастся.

	} else {
  Иначе — все остальные случаи, то есть длина 2 и больше.

		var res strings.Builder
  Создаём накопитель строк — переменную res типа strings.Builder. Накопитель нужен, чтобы дописывать символы по одному и в конце забрать всё разом.
  Форма var имя Тип объявляет переменную БЕЗ начального значения — она получает нулевое значение своего типа. Для Builder нулевое значение уже готово к работе, ничего дополнительно создавать не надо.
  Отличие от := : var res strings.Builder задаёт тип явно и не требует значения; res := ... вывел бы тип из значения справа.

		i := 0
  Создаём переменную-счётчик i и кладём в неё 0. Знак := — создание новой переменной. i объявлена ЗДЕСЬ, снаружи цикла, это важно для следующей строки.

		for i = 0; i < int(len(str)/2); i++ {
  Заголовок цикла из трёх частей.
  1) i = 0 — один знак =, это ПРИСВАИВАНИЕ уже существующей переменной, а не создание. Так написано потому, что i создана строкой выше. 🔴 Если поставить здесь :=, Go создаст вторую переменную i внутри цикла, а внешняя останется неиспользованной — компилятор откажется собирать код с ошибкой «declared and not used».
  2) i < int(len(str)/2) — условие продолжения. Крутим, пока i меньше половины длины.
     len(str)/2 — деление двух целых чисел, а целочисленное деление в Go само отбрасывает дробную часть. Для длины 11 получится 5, а не 5.5. То есть «округление вниз» из условия достаётся бесплатно, никаких функций округления не нужно.
     int(...) — преобразование к типу int. Здесь оно избыточно, потому что len уже даёт int, но в эталоне написано так.
  🔴 Знак строго < , а не <= . При <= взялся бы один лишний символ: для "Hello World" вышло бы "Hello " вместо "Hello".
  3) i++ — после каждого прохода увеличить i на единицу.

			res.WriteRune(rune(str[i]))
  Дописываем в накопитель очередной символ.
  str[i] — обращение к i-му элементу строки. Оно даёт БАЙТ (тип byte, число от 0 до 255), а не символ и не строку.
  rune(str[i]) — преобразование байта в руну. Руна — целое число, обозначающее номер символа в таблице Unicode.
  res.WriteRune(...) — метод накопителя, дописывает эту руну в конец накопленного. Запись через точку означает «вызвать функцию, принадлежащую этому объекту».
  🔴 len и str[i] работают с БАЙТАМИ, а не с буквами. Для латиницы, цифр и пробелов один байт = одна буква, и всё сходится. Для кириллицы одна буква занимает два байта, поэтому «половина» посчитается по байтам, и текст может порезаться посередине буквы. Задание проверяют на латинице, эталон это устраивает.

		}
  Конец тела цикла.

		return res.String()
  res.String() отдаёт всё накопленное как обычную строку, её и возвращаем.

	}
}
  Закрываются else и сама функция.
  🔴 Обрати внимание: return стоит в КАЖДОЙ из трёх веток if/else if/else. Именно поэтому в конце функции не нужен ещё один return — компилятор видит, что любой путь заканчивается возвратом значения. Если убрать else и оставить ветки «плоскими», понадобится финальный return, иначе будет ошибка «missing return».

Проверка на примере из условия: "Hello World", len = 11, 11/2 = 5, цикл берёт байты с 0 по 4 — это "Hello". Совпадает.


------------------------------------------------------------------------------
  ТЕРМИНЫ, КОТОРЫЕ ЗДЕСЬ ВСТРЕТИЛИСЬ
------------------------------------------------------------------------------
  * срез строки str[a:b] — часть строки с позиции a включительно до позиции
  b НЕ включительно
  * str[:X] — срез от начала строки до позиции X; пустое место слева от
  двоеточия означает ноль
  * len(str) — длина строки в байтах
  * целочисленное деление — деление, при котором дробная часть
  отбрасывается: 11 / 2 равно 5, 1 / 2 равно 0
  * позиция (индекс) — номер символа в строке, счёт начинается с нуля:
  первый символ имеет позицию 0
  * string — тип строки
  * байт — единица хранения; латинская буква занимает один байт,
  кириллическая — два, поэтому len для кириллицы больше числа символов
  * return — закончить функцию и отдать значение

  ГДЕ ЗАВАЛИВАЮТСЯ НА ЭТОЙ ЗАДАЧЕ

  * Забыть отдельный случай длины 1. Деление 1 / 2 в целых числах даёт 0,
  срез str[:0] вернёт пустую строку, а по условию нужно "A". Проверено
  прогоном: с отдельной веткой "A" -> "A".
  * Округлить вверх. "Hello World" (11 символов) должно дать "Hello" — пять
  символов. Формула вроде (len(str)+1)/2 даст шесть и провалит тест.
  * Написать str[:len(str)/2 - 1] — потеряется один символ, потому что конец
  среза и так не входит в результат.
  * Ставить проверку len(str) == 1 после общей формулы — она никогда не
  выполнится, так как return выше уже завершит функцию.
  * Дописывать отдельную ветку для пустой строки. Она не нужна: 0/2 = 0,
  срез str[:0] даёт "" и не вызывает падения. Проверено прогоном.
  * len считает байты. Для строки из кириллицы срез может разрезать символ
  пополам и дать испорченный текст; в примерах задания только латиница.
  * Перепутать двоеточие в срезе с запятой или написать str[0, len(str)/2] —
  это ошибка компиляции.
