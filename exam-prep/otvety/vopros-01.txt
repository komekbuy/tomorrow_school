------------------------------------------------------------------------------
  ЧТО ПРОСЯТ СДЕЛАТЬ
------------------------------------------------------------------------------
  Нужно написать программу, которая печатает на экран один символ — цифру 1
  — и больше ничего. В разделе Usage видно, что программу запускают тремя
  способами: без аргументов, с двумя аргументами и с тремя. Во всех трёх
  случаях вывод одинаковый: строка "1". То есть аргументы командной строки
  программа обязана полностью игнорировать.


------------------------------------------------------------------------------
  КАК ДУМАТЬ НАД ЗАДАЧЕЙ (читать до кода)
------------------------------------------------------------------------------
  Сначала пойми, что от тебя требуют: не функцию, которую кто-то вызовет, а
  самостоятельную программу — значит пакет main и функция main внутри.
  Дальше смотри на Usage: три запуска с разными аргументами дают один и тот
  же вывод, значит никакой работы с аргументами делать не надо, os.Args
  трогать не нужно вообще. Задача сводится к одному действию: вывести
  символ. Теперь реши, что именно выводить: в примере после "1" следующая
  строка терминала начинается с приглашения $, значит после единицы стоит
  перевод строки. Итого нужно вывести ровно два байта: сам символ 1 и символ
  конца строки. В Piscine Go для посимвольной печати используют пакет
  github.com/01-edu/z01 и его функцию PrintRune — она печатает ровно одну
  руну за вызов. Значит вызовов будет два: первый печатает '1', второй
  печатает '\n'. Порядок важен: сначала символ, потом перевод строки, иначе
  вывод будет перевёрнут. Никаких переменных, циклов и условий здесь не
  нужно — любая лишняя строка кода это лишний шанс ошибиться. Проверь себя
  мысленно: программа запускается, выполняет два вызова, завершается,
  аргументы нигде не читаются — условие выполнено для всех трёх запусков
  сразу.

  СВЕРЕНО С ЭТАЛОНОМ ШКОЛЫ: 🔴 ГЛАВНОЕ: печатается ТОЛЬКО сам символ, без
  перевода строки. В задании сказано «and nothing else» — лишний \n это и
  есть «что-то ещё», и задача не засчитывается. Эталон школы делает ровно
  один вызов PrintRune и на этом заканчивает.

  ПРО ПАКЕТЫ: здесь приведён код ЭТАЛОНА ШКОЛЫ — ровно тот, с которым бот
  сравнивает твой ответ. Значит все пакеты, которые он подключает, для этого
  задания разрешены: будь иначе, проверка не собралась бы.

    	z01.PrintRune('1')
    }


------------------------------------------------------------------------------
  РАЗБОР ПО СТРОКАМ
------------------------------------------------------------------------------
package main
— объявление пакета. Слово main говорит компилятору Go: это не библиотека, а исполняемая программа, её можно запустить через go run. Если написать здесь любое другое слово, запустить файл будет нельзя.

(пустая строка)
— gofmt требует пустую строку между объявлением пакета и блоком импортов. Без неё gofmt -l покажет файл как неотформатированный.

import "github.com/01-edu/z01"
— подключение внешнего пакета z01 из школьной библиотеки 01-edu. Только после этой строки можно писать z01.чтото. Кавычки двойные и обязательны — это путь к пакету, то есть строка.

(пустая строка)

func main() {
— начало функции main. func — ключевое слово, которым в Go объявляют функцию. main — её имя; именно функцию с таким именем в пакете main операционная система запускает первой. Круглые скобки пустые — функция ничего не принимает. Она также ничего не возвращает, поэтому после скобок сразу открывается фигурная скобка { — тело функции.

	z01.PrintRune('1')
— вызов функции PrintRune из пакета z01. Точка означает "взять из пакета z01 то, что называется PrintRune". В скобках передаём '1' — это руна, то есть один символ; одинарные кавычки обозначают именно один символ, а не строку. PrintRune выводит этот символ в стандартный вывод (на экран). После этой строки на экране появилась цифра 1, но курсор ещё стоит рядом с ней на той же строке. Строка начинается с табуляции — так требует gofmt для кода внутри функции.

	z01.PrintRune('\n')
— второй вызов той же функции. '\n' — это один символ перевода строки, несмотря на то, что записан он двумя знаками: обратный слэш и буква n. Обратный слэш здесь служебный, он говорит: следующий знак читать не как букву n, а как специальный символ. После этого вызова курсор переходит на новую строку, и приглашение терминала $ печатается уже под единицей — ровно как в README.

}
— закрывающая фигурная скобка тела функции main. Программа доходит до неё и завершается.

  ТЕРМИНЫ, КОТОРЫЕ ЗДЕСЬ ВСТРЕТИЛИСЬ
------------------------------------------------------------------------------
  * пакет (package) — именованная группа файлов на Go; пакет с именем main
  особый, только из него получается запускаемая программа
  * main — имя функции, с которой начинается выполнение программы; без неё
  программа не запустится
  * func — ключевое слово Go, с которого начинается объявление любой функции
  * import — команда подключить чужой пакет, чтобы пользоваться его
  функциями
  * github.com/01-edu/z01 — школьный пакет 01-edu с функцией PrintRune для
  посимвольного вывода
  * z01.PrintRune — функция, которая печатает на экран ровно один символ за
  один вызов, ничего не добавляя от себя
  * руна (rune) — один символ в Go; записывается в одинарных кавычках,
  например '1' или 'B'
  * одинарные кавычки — обозначают один символ (руну); двойные кавычки
  обозначают строку, это разные вещи
  * '\n' — один символ перевода строки, из-за которого следующий вывод
  начинается с новой строки
  * стандартный вывод (stdout) — поток, в который программа пишет текст и
  который по умолчанию виден в терминале
  * аргументы командной строки — слова, написанные после имени программы при
  запуске; в этой задаче они не используются
  * go.mod — файл с именем модуля и списком внешних пакетов, без него go run
  не найдёт z01


------------------------------------------------------------------------------
  ГДЕ ЗАВАЛИВАЮТСЯ НА ЭТОЙ ЗАДАЧЕ
------------------------------------------------------------------------------
  * Написать двойные кавычки вместо одинарных: PrintRune("1") не
  скомпилируется, потому что PrintRune принимает руну, а не строку.
  * Забыть z01.PrintRune('\n'). Вывод получится без перевода строки и не
  совпадёт с README побайтово — проверяющий засчитает ошибку.
  * Поставить перевод строки первым, а цифру вторым — порядок вызовов задаёт
  порядок символов на экране.
  * Начать читать os.Args и что-то печатать в зависимости от аргументов. По
  Usage вывод одинаковый при 0, 2 и 3 аргументах, любая зависимость от
  аргументов ломает задачу.
  * Напечатать что-то ещё: приветствие, пробел, вторую строку. В условии
  сказано "and nothing else" — вывод должен быть ровно два байта.
  * Забыть go.mod с require github.com/01-edu/z01: программа не соберётся с
  ошибкой о ненайденном пакете. Лечится go mod init <имя> и go get
  github.com/01-edu/z01.
  * Назвать пакет не main: тогда go run выдаст ошибку, что нет исполняемого
  пакета.
  * Напечатать перевод строки после символа. Задание требует «и ничего
  больше» — лишний \n валит задачу.

РАЗБОР ПО СТРОКАМ — onlya

package main
  Это ПРОГРАММА, а не функция. Пакет main плюс функция main = файл, который можно запустить. Если написать другое имя пакета, программа не запустится.

import "fmt"
  Подключается один пакет — fmt, из него нужна одна функция, Print. Когда пакет ровно один, скобки не нужны и импорт пишется в строку.
  Раз эталон школы использует fmt — для этого задания пакет разрешён.

func main() {
  Точка входа: с этой функции начинается выполнение программы. Скобки пустые — параметров нет. Возвращаемого типа нет — main ничего не возвращает.

	fmt.Print("a")
  Печатает на экран строку из одного символа — маленькую латинскую a. Двойные кавычки = строка (одинарные дали бы руну, отдельный тип).
  🔴 Именно Print, а не Println. Разница между ними ровно одна: Println сам дописывает в конце перевод строки, Print — нет. Эталон школы использует Print, значит после буквы ничего не выводится. Напишешь Println — вывод отличается на один невидимый символ \n, и бот засчитает ответ неверным.
  🔴 Никакого \n внутри кавычек тоже не должно быть.

}
  Закрывающая скобка функции main. Программа заканчивается.

ЧТО ЛЕГКО ПЕРЕПУТАТЬ
  Аргументы командной строки здесь не читаются вообще — пакет os не импортирован и не нужен. Что бы ни передали при запуске, вывод один и тот же.
  Всё задание — четыре смысловые строки. Проверять надо не логику, а точность: имя пакета main, импорт fmt, Print (не Println), буква a в двойных кавычках.

  пакета github.com/01-edu/z01: один вызов печатает ровно одну руну. Значит
  решение — два вызова подряд: сначала 'z', затем '\n'. Не путай имя пакета
  z01 с буквой z, которую печатаем: пакет называется z01 по названию
  школьной библиотеки, а руна 'z' в одинарных кавычках — это просто буква.
  Самопроверка: вывод должен быть ровно два байта, 0x7a и 0x0a.

  СВЕРЕНО С ЭТАЛОНОМ ШКОЛЫ: 🔴 ГЛАВНОЕ: печатается ТОЛЬКО сам символ, без
  перевода строки. В задании сказано «and nothing else» — лишний \n это и
  есть «что-то ещё», и задача не засчитывается. Эталон школы делает ровно
  один вызов PrintRune и на этом заканчивает.

  ПРО ПАКЕТЫ: здесь приведён код ЭТАЛОНА ШКОЛЫ — ровно тот, с которым бот
  сравнивает твой ответ. Значит все пакеты, которые он подключает, для этого
  задания разрешены: будь иначе, проверка не собралась бы.

РАЗБОР ПО СТРОКАМ — onlyz

package main
  Это ПРОГРАММА, а не функция. Пакет main плюс функция main = файл, который можно запустить. С другим именем пакета запуска не будет.

import "fmt"
  Подключается один пакет — fmt, из него нужна одна функция, Print. Когда пакет ровно один, скобки не нужны и импорт пишется в строку.
  Раз эталон школы использует fmt — для этого задания пакет разрешён.

func main() {
  Точка входа: выполнение программы начинается отсюда. Пустые скобки — параметров нет. Возвращаемого типа нет — main ничего не возвращает.

	fmt.Print("z")
  Печатает на экран строку из одного символа — маленькую латинскую z. Двойные кавычки = строка (одинарные дали бы руну, отдельный тип).
  🔴 Именно Print, а не Println. Разница между ними ровно одна: Println сам дописывает перевод строки в конце, Print — нет. Эталон школы использует Print, значит после буквы в вывод ничего не уходит. Напишешь Println — вывод отличается на невидимый символ \n, и ответ не зачтётся.
  🔴 \n внутри кавычек тоже писать не надо.

}
  Закрывающая скобка функции main. Программа заканчивается.

ЧТО ЛЕГКО ПЕРЕПУТАТЬ
  Задание onlyz отличается от onlya ровно одним символом внутри кавычек. Всё остальное — слово в слово то же самое.
  Аргументы командной строки не читаются: пакет os не импортирован и не нужен. Что бы ни передали при запуске, вывод одинаковый.


------------------------------------------------------------------------------
  ТЕРМИНЫ, КОТОРЫЕ ЗДЕСЬ ВСТРЕТИЛИСЬ
------------------------------------------------------------------------------
  * пакет main — пакет, из которого Go собирает запускаемую программу
  * func main() — функция, с которой начинается выполнение программы
  * import — подключение внешнего пакета, чтобы пользоваться его функциями
  * github.com/01-edu/z01 — школьный пакет 01-edu; его имя z01 не имеет
  отношения к печатаемой букве z
  * z01.PrintRune — печатает ровно один символ в стандартный вывод
  * руна (rune) — один символ в Go, записывается в одинарных кавычках: 'z'
  * одинарные кавычки — один символ; двойные кавычки — строка, это разные
  типы
  * '\n' — один символ перевода строки, код 10
  * стандартный вывод (stdout) — поток, куда программа пишет текст, по
  умолчанию виден в терминале
  * тело функции — код между { и }, выполняется при вызове функции
  * gofmt — встроенный форматтер Go, требует табуляцию для отступов
  * go.mod — файл модуля с его именем и списком внешних зависимостей

  * Решить, что раз Usage в README нет, проверки запуском не будет. Проверка

  * Напечатать лишнее: пробел, точку, вторую строку. В условии сказано and
  nothing else.
  * Забыть go.mod с require github.com/01-edu/z01 — сборка упадёт с ошибкой
  о ненайденном пакете.
  * Напечатать перевод строки после символа. Задание требует «и ничего
  больше» — лишний \n валит задачу.
