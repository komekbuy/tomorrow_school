ЗАЧЕМ ОНИ ВООБЩЕ НУЖНЫ
================================================================================

Обычная переменная хранит ОДНО значение:

    x := 5          в x лежит одно число

Слайс хранит МНОГО значений сразу, под одним именем:

    nums := []int{5, 7, 9}     в nums лежат три числа

Зачем это надо. Представь задачу: «прочитать 100 чисел и найти среди них
самое большое». Без слайса пришлось бы завести 100 переменных:
x1, x2, x3 ... x100 — и написать 100 сравнений руками.
Со слайсом это один цикл на три строки.

ГЛАВНОЕ ОТЛИЧИЕ ОТ ВСЕГО, ЧТО БЫЛО РАНЬШЕ:
Раньше накопитель хранил ИТОГ (одно число, одну строку).
Слайс хранит ВСЕ ЗНАЧЕНИЯ по отдельности — к любому можно вернуться позже.

    count := 0     -> в конце знаем только сумму, сами числа потеряны
    var a []int    -> в конце знаем каждое число, можно перебрать заново

Где встречается в заданиях школы:
  - вернуть набор значений (диапазон чисел, квадраты, комбинации)
  - разбить строку на слова -> получается []string
  - os.Args — это тоже слайс строк
  - отсортировать что-то

================================================================================
КОНСПЕКТ — 6 ПРАВИЛ
================================================================================

1. []int — слайс чисел. []string — слайс строк. Квадратные скобки ПУСТЫЕ.

2. var a []int         — пустой слайс, ноль элементов
   a := []int{1, 2, 3} — сразу с содержимым

3. append ДОБАВЛЯЕТ и ВОЗВРАЩАЕТ НОВЫЙ слайс:
       a = append(a, 7)      правильно
       append(a, 7)          НЕ РАБОТАЕТ, результат потерян

4. len(a) — сколько элементов. Здесь честно считает элементы,
   в отличие от строк, где len считал байты.

5. a[0] — первый элемент. Нумерация с нуля.
   Последний — a[len(a)-1]. Обратиться к a[len(a)] = паника.

6. Перебор такой же, как у строк:
       for i, v := range a      i — номер, v — значение
   Но номера идут ПОДРЯД (0,1,2...), без скачков.

[10]int — это МАССИВ, не слайс. Размер зашит намертво и обязан быть
константой. [size]int с переменной size не соберётся:
       non-constant array bound size
Именно поэтому в заданиях используют слайсы.

================================================================================
ПРИМЕРЫ — ЦЕПОЧКА ПО ОДНОМУ ИЗМЕНЕНИЮ
================================================================================

    package main
    import "fmt"
    func main() {
        // сюда тело примера
    }

--- 1 --- создать слайс со значениями
    nums := []int{10, 20, 30}
    fmt.Println(nums)
    -> [10 20 30]

--- 2 --- отличие от 1: сколько элементов
    nums := []int{10, 20, 30}
    fmt.Println(len(nums))
    -> 3

--- 3 --- отличие от 2: взять один элемент
    nums := []int{10, 20, 30}
    fmt.Println(nums[0])
    -> 10
    ПЕРВЫЙ элемент имеет номер 0, а не 1.

--- 4 --- отличие от 3: последний элемент
    nums := []int{10, 20, 30}
    fmt.Println(nums[len(nums)-1])
    -> 30
    ПОЧЕМУ -1: элементов 3, а номера 0,1,2. Последний номер всегда len-1.

--- 5 --- отличие от 3: выход за границу
    nums := []int{10, 20, 30}
    fmt.Println(nums[3])
    -> ПАДЕНИЕ: index out of range [3] with length 3
    Номера только 0,1,2. Номера 3 не существует.

--- 6 --- пустой слайс
    var nums []int
    fmt.Println(nums, len(nums))
    -> [] 0

--- 7 --- отличие от 6: добавили элемент
    var nums []int
    nums = append(nums, 5)
    fmt.Println(nums, len(nums))
    -> [5] 1

--- 8 --- отличие от 7: забыли присвоить результат
    var nums []int
    append(nums, 5)
    -> НЕ СОБЕРЁТСЯ: append(...) evaluated but not used
    append возвращает НОВЫЙ слайс. Результат надо класть обратно.

--- 9 --- набираем в цикле
    var nums []int
    for i := 1; i <= 5; i++ {
        nums = append(nums, i)
    }
    fmt.Println(nums)
    -> [1 2 3 4 5]

--- 10 --- отличие от 9: кладём не i, а i*i
    var nums []int
    for i := 1; i <= 5; i++ {
        nums = append(nums, i*i)
    }
    fmt.Println(nums)
    -> [1 4 9 16 25]

--- 11 --- отличие от 9: с фильтром
    var nums []int
    for i := 1; i <= 10; i++ {
        if i%2 == 0 {
            nums = append(nums, i)
        }
    }
    fmt.Println(nums)
    -> [2 4 6 8 10]

--- 12 --- перебор слайса
    nums := []int{10, 20, 30}
    for i, v := range nums {
        fmt.Println(i, v)
    }
    -> 0 10 / 1 20 / 2 30
    Номера ПОДРЯД — в отличие от строк, где они скакали.

--- 13 --- сумма элементов
    nums := []int{10, 20, 30}
    sum := 0
    for _, v := range nums {
        sum = sum + v
    }
    fmt.Println(sum)
    -> 60
    Тот же накопитель, что в блоке B. Только берём не буквы, а числа.

--- 14 --- отличие от 13: ищем максимум
    nums := []int{10, 50, 30}
    max := nums[0]
    for _, v := range nums {
        if v > max {
            max = v
        }
    }
    fmt.Println(max)
    -> 50
    ВАЖНО: max стартует с ПЕРВОГО элемента, а не с нуля.
    Если стартовать с 0, на слайсе из отрицательных чисел получим неверный ответ.

--- 15 --- изменить элемент
    nums := []int{10, 20, 30}
    nums[1] = 99
    fmt.Println(nums)
    -> [10 99 30]
    В отличие от строк, слайс МЕНЯТЬ МОЖНО.

--- 16 --- слайс строк
    words := []string{"Hello", "world"}
    for _, w := range words {
        fmt.Println(w)
    }
    -> Hello / world

--- 17 --- склеить слайс строк
    words := []string{"a", "b", "c"}
    out := ""
    for _, w := range words {
        out = out + w
    }
    fmt.Println(out)
    -> abc

--- 18 --- поменять два элемента местами
    nums := []int{10, 20, 30}
    nums[0], nums[2] = nums[2], nums[0]
    fmt.Println(nums)
    -> [30 20 10]
    Слева и справа одновременно — Go меняет их за один шаг.

--- 19 --- развернуть слайс
    nums := []int{1, 2, 3, 4, 5}
    for i, j := 0, len(nums)-1; i < j; i, j = i+1, j-1 {
        nums[i], nums[j] = nums[j], nums[i]
    }
    fmt.Println(nums)
    -> [5 4 3 2 1]
    Два счётчика: один идёт с начала, второй с конца, встречаются в середине.

--- 20 --- отсортировать (сортировка выбором)
    nums := []int{30, 10, 20}
    for i := 0; i < len(nums); i++ {
        for j := i + 1; j < len(nums); j++ {
            if nums[j] < nums[i] {
                nums[i], nums[j] = nums[j], nums[i]
            }
        }
    }
    fmt.Println(nums)
    -> [10 20 30]

================================================================================
ГРАБЛИ
================================================================================

1) ЗАБЫТЬ ПРИСВОИТЬ РЕЗУЛЬТАТ append
   БЫЛО:  append(nums, 5)
   СТАЛО: nums = append(nums, 5)

2) ВЫХОД ЗА ГРАНИЦУ
   Последний элемент — a[len(a)-1], а не a[len(a)].
   Обращение к a[len(a)] роняет программу.

3) МАКСИМУМ, НАЧАТЫЙ С НУЛЯ
   max := 0 сломается на слайсе из отрицательных чисел.
   Стартовать надо с первого элемента: max := a[0].
   Но тогда пустой слайс уронит программу — проверять len(a) == 0 отдельно.

4) nil ПРОТИВ ПУСТОГО СЛАЙСА
   var a []int          -> nil,     len 0,  печатается []
   b := []int{}         -> НЕ nil,  len 0,  печатается []
   Выглядят одинаково, строгое сравнение их различает.
   Если в задании написано «returns a nil slice» — нужен первый вариант.

5) МАССИВ ВМЕСТО СЛАЙСА
   Ошибка non-constant array bound size означает, что написано [n]int
   с переменной n. Убрать число из скобок — станет слайсом.

6) len НА СЛАЙСЕ И НА СТРОКЕ — РАЗНОЕ
   На слайсе len честно считает элементы.
   На строке len считает БАЙТЫ, а не буквы. Не путать.

ЗАДАЧИ (без образца)
================================================================================

1. func Range(min, max int) []int
   Слайс от min до max-1.  Range(5,10) -> [5 6 7 8 9]
   Если min >= max -> пустой слайс

2. func SumSlice(a []int) int
   Сумма элементов. Пустой слайс -> 0

3. func MaxSlice(a []int) int
   Максимум. Пустой слайс -> 0

4. func CountEven(a []int) int
   Сколько чётных.  [1 2 3 4] -> 2

5. func ReverseSlice(a []int) []int
   Развернуть.  [1 2 3] -> [3 2 1]

6. func Doubles(a []int) []int
   Каждый элемент умножить на 2.  [1 2 3] -> [2 4 6]

  ТРИ МЕСТА НАКОПИТЕЛЯ — ОДИНАКОВЫ ДЛЯ ВСЕХ ТИПОВ:

      число:   count := 0        строка:  out := ""      слайс:  var a []int
               count = count+1            out = out+x            a = append(a,x)
               return count               return out             return a

      создать ДО цикла  ->  дополнять ВНУТРИ  ->  вернуть ПОСЛЕ

  Меняется только тип накопителя и способ дополнения.
  Логика одна и та же во всех задачах.
