Скелет

начало 
package main

import "fmt"

func main() {
    fmt.Println("привет")
}
package main + func main = запускаемый файл. Другое имя пакета — библиотека, она не запускается.

Переменные

хранение 
x := 10          // создать
x = 20           // изменить
var z int        // z == 0
const Pi = 3.14  // не менять
:=создать новую
=записать в существующую
:= только внутри функций. Снаружи — var и const.

Типы

и нули
intцелое · ноль 0
float64дробное · 0
stringтекст · ""
boolда/нет · false
byte0–255, он же uint8
runeсимвол, он же int32
7/2 == 3 — целые делятся нацело. И типы сами не приводятся: int + float64 не соберётся.

Строки и руны

ловушка №1 
s := "Привет"
len(s)   // 12 — это БАЙТЫ
s[0]    // 208 — байт, не буква

for _, r := range s {}  // r — руна
[]rune(s)             // длина 6
s[i] даёт байт, range даёт символ. Латиница 1 байт, кириллица 2. Строку менять нельзя.

Условия

развилки 
if n > 0 && n < 10 {
} else {
}

switch c {
case 'a', 'e':   // break не нужен
default:
}
&& — верны оба условия. || — хотя бы одно.

Циклы

for — единственный 
for i := 0; i < 10; i++ {}  // счётчик
for n > 0 {}              // пока верно
for {}                    // вечный
for i, v := range s {}     // по элементам
breakвыйти из цикла совсем
continueк следующему шагу
В Go нет while и do-while — только for во всех видах.

Функции

приняли → вернули 
func Sum(a, b int) int {
    return a + b
}

// два значения сразу:
func Div(a, b int) (int, error)
return прерывает функцию сразу — код после него не выполнится. Имя с большой буквы = видно снаружи пакета.

Слайсы

длина меняется 
s := []int{1, 2, 3}
s = append(s, 4)   // s = обязательно!
len(s)  cap(s)      // длина, вместимость
s[1:3]              // с 1 по 2
Слайс — окно в общий массив. b := a копирует окно, не данные: пишешь в b — меняется a. Копия — через copy.

Map

ключ → значение 
m := make(map[string]int)
m["a"] = 1
delete(m, "a")
v, ok := m["нет"]  // 0, false
ok говорит, лежит ли ключ вообще. Порядок обхода случайный — Go мешает его нарочно.

Указатели

и структуры 
type User struct {
    Name string
    Age  int
}

func Older(u *User) { u.Age++ }
Older(&u)   // & — взять адрес
Без * функция получает копию, и снаружи изменений не видно.

Ошибки

это значение 
n, err := strconv.Atoi(s)
if err != nil {
    // не получилось
}
// сюда — только если всё хорошо
В Go нет try/catch. nil = ошибки не было. Ошибку возвращают вторым значением и проверяют сразу.

Грабли, на которые наступают все

✕Печать ≠ возврат. Тест смотрит на return, экран он не видит.
✕append без присваивания. Надо s = append(s, x).
✕s[i] — байт, не буква. Нужен range или []rune.
✕&& вместо ||. Подставь число и прочитай вслух.
✕Запись в nil map. Без make падает на первой записи.
✕Дробные через ==. 0.1+0.2 ≠ 0.3, сравнивай разницу.
✕Ошибка на единицу. i < len(s), а не <=.
✕Лишняя переменная. В Go это ошибка сборки, не warning.
✕Забыл gofmt. Прогоняй перед каждой сдачей.
