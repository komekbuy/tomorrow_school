    go run . | cat -e

Форматирование (запускай перед каждым пушем):
    gofmt -w main.go

ЧАСТЫЕ ОШИБКИ ПРИ ЗАПУСКЕ:
    go run              -> "no go files listed"   забыл точку, нужно: go run .
    нет go.mod          -> "go.mod file not found" сделай go mod init <имя>
    import без вызова   -> "imported and not used" в Go это ОШИБКА, не warning
    переменная не нужна -> "declared and not used" тоже ошибка, убери или юзай _

Папка: mkdir tema1 && cd tema1 && go mod init tema1 && go get github.com/01-edu/z01

ЧТО НАДО ЗНАТЬ ДО НАЧАЛА:
z01.PrintRune печатает РОВНО ОДИН символ за вызов. Не строку, не число.
Символ пишется в ОДИНАРНЫХ кавычках: 'a'. В двойных "a" — это уже строка,
другой тип, функция её не примет.

Символ внутри компьютера — это число (таблица ASCII):
    '0'=48  '1'=49 ... '9'=57
    'A'=65  'B'=66 ... 'Z'=90
    'a'=97  'b'=98 ... 'z'=122
Цифры и буквы идут ПОДРЯД — поэтому по ним можно идти циклом.


--- Пример 1 ---
package main

import "github.com/01-edu/z01"

func main() {
	z01.PrintRune('g')
	z01.PrintRune('o')
	z01.PrintRune('\n')
}

Что тут: цикла нет, каждый символ отдельным вызовом.
Вывод: go


--- Пример 2 ---
package main

import "github.com/01-edu/z01"

func main() {
	for c := 'a'; c <= 'f'; c++ {
		z01.PrintRune(c)
	}
	z01.PrintRune('\n')
}

Что тут: цикл из трёх частей — старт (c := 'a'), условие (c <= 'f'),
шаг (c++). Пока условие истинно, тело повторяется.
Вывод: abcdef

ЧТО НАДО ЗНАТЬ ДО НАЧАЛА:
Функция — это набор команд с именем. Объявить функцию — написать рецепт,
вызвать — воспользоваться им. Объявление само по себе ничего не делает.

Функция бывает двух видов:
    func Name(x int)     { }    ничего не возвращает — делает что-то сама
    func Name(x int) int { }    возвращает int, ОБЯЗАН быть return

Если функция объявлена в том же пакете — вызываешь просто Name(...).
Если в другом (как piscine) — piscine.Name(...).

В этой теме местами используется fmt.Println, чтобы видеть числа.
В заданиях школы fmt обычно ЗАПРЕЩЁН — там только PrintRune. Смотри
раздел Allowed functions в своём subject.

func main() {

	Line()

ЧТО НАДО ЗНАТЬ ДО НАЧАЛА:
Главный приём этой темы: если второй цикл стартует НЕ с нуля, а с
значения первого плюс один — получаются пары, где второй элемент
всегда больше первого. Без повторов и без обратного порядка.

Второй приём: разделитель между элементами печатается везде, кроме
последнего элемента. Лишняя запятая в конце заваливает тест.


--- Пример 1 ---
package main

import "github.com/01-edu/z01"

func main() {
	for a := '0'; a <= '2'; a++ {
		for b := '0'; b <= '2'; b++ {
			z01.PrintRune(a)
			z01.PrintRune(b)
			z01.PrintRune(' ')
		}
	}
	z01.PrintRune('\n')
}

Что тут: обычные вложенные циклы — ВСЕ сочетания, включая 00, 11, 22
и обратные пары (10 при наличии 01).
Вывод: 00 01 02 10 11 12 20 21 22


--- Пример 2 ---
package main

import "github.com/01-edu/z01"

}

Что тут: ВОТ ГЛАВНОЕ ОТЛИЧИЕ. Внутренний цикл стартует с a+1 —
поэтому вторая цифра всегда больше первой. Повторов нет, обратных пар нет.
Вывод: 01 02 03 12 13 23

|| означает "или": достаточно чтобы хоть один символ отличался.
Вывод: ab, ac, ad, bc, bd, cd

ЧТО НАДО ЗНАТЬ ДО НАЧАЛА:
Два оператора, без которых тут никак:
    /   деление НАЦЕЛО      17 / 10 = 1     (дробная часть отбрасывается)
    %   остаток от деления  17 % 10 = 7

Комбинация даёт разбор числа на цифры:
    n % 10   -> последняя цифра
    n / 10   -> всё, кроме последней цифры

Рекурсия — функция, которая вызывает саму себя. Нужна, когда количество
шагов заранее неизвестно (число может быть из 1 цифры, а может из 15).

ЛОВУШКА С МИНИМАЛЬНЫМ ЧИСЛОМ (её проверяют тесты!):
Диапазон int:  от -9223372036854775808  до  +9223372036854775807
Он НЕСИММЕТРИЧНЫЙ — минимум по модулю на единицу больше максимума.
Поэтому n = -n для минимального числа ЛОМАЕТСЯ: такого положительного
числа не существует, происходит переполнение.
Решение: работать не с положительными, а с ОТРИЦАТЕЛЬНЫМИ числами.

	fmt.Println(n / 100)
}

ЧТО НАДО ЗНАТЬ ДО НАЧАЛА:
Когда переменную передают в функцию, Go передаёт КОПИЮ. Функция меняет
копию, оригинал остаётся прежним. Это главная проблема, которую решают
указатели.

Аналогия: дал другу ксерокопию тетради — он пишет в копию, твоя тетрадь
чистая. Дал бумажку с адресом — он идёт и пишет в оригинал.

Два символа:
    &x    взять АДРЕС переменной x
    *p    значение ПО АДРЕСУ p (разыменование)

Звёздочка означает разное в зависимости от места:
    func F(n *int)   рядом с типом — "указатель на int"
    *n = 1           перед переменной — действие "положить по адресу"


--- Пример 1 ---
package main

import "fmt"

func Bad(n int) {
	n = 100
}

func main() {
	x := 5
	Bad(x)
	fmt.Println(x)
}

Что тут: функция получила КОПИЮ и изменила её. Оригинал не тронут.
Вывод: 5


--- Пример 2 ---
package main

import "fmt"

func Good(n *int) {
	*n = 100
}

func main() {
	x := 5
	Good(&x)
	fmt.Println(x)
}

Что тут: то же самое, но через указатель. Передали АДРЕС (&x),
функция пошла по адресу и записала туда (*n = 100). Оригинал изменился.
Сравни с примером 1 — разница в трёх символах.
Вывод: 100

	fmt.Println(*p)

Что тут: p хранит адрес x. Через *p можно и читать, и писать —
это доступ к той же самой ячейке памяти.

ЧТО НАДО ЗНАТЬ ДО НАЧАЛА:
Строка в Go НЕИЗМЕНЯЕМА. Написать s[0] = 'A' нельзя — не скомпилируется.
Чтобы менять, надо преобразовать в срез, изменить и вернуть обратно:
    r := []rune(s)     строка -> срез рун
    r[0] = 'A'         теперь можно менять

Русская буква занимает 2 байта — через []byte её разрежет пополам.

len(s) считает БАЙТЫ, а не символы. Для подсчёта символов нужен range.

package main

import "fmt"

func Reverse(s string) string {
	r := []rune(s)
	for i, j := 0, len(r)-1; i < j; i, j = i+1, j-1 {
		r[i], r[j] = r[j], r[i]
	}
	return string(r)
}

func main() {
	fmt.Println(Reverse("golang"))
}

Что тут: разворот строки. Два счётчика идут навстречу друг другу:
i с начала, j с конца, меняются местами. Цикл останавливается,
когда они встретились посередине.
Вывод: gnalog

ЧТО НАДО ЗНАТЬ ДО НАЧАЛА:
Главная формула накопления числа:
    result = result*10 + цифра

Умножение на 10 сдвигает разряды влево, потом добавляется новая цифра:
    "347":  0*10+3 = 3  ->  3*10+4 = 34  ->  34*10+7 = 347

Символ в число:  c - '0'   (например '7' - '0' = 55 - 48 = 7)
Проверка цифры:  c >= '0' && c <= '9'

package main

import "fmt"

func Parse(s string) int {
	r := []rune(s)
	if len(r) == 0 {
		return 0
	}
	sign := 1
	i := 0
	if r[0] == '+' || r[0] == '-' {
		if r[0] == '-' {
			sign = -1
		}
		i = 1
	}
	if i == len(r) {
		return 0
	}
	result := 0
	for ; i < len(r); i++ {
		if r[i] < '0' || r[i] > '9' {
			return 0
		}
		result = result*10 + int(r[i]-'0')
	}
	return result * sign
}

func main() {
	fmt.Println(Parse("42"))
	fmt.Println(Parse("+42"))
	fmt.Println(Parse("-42"))
	fmt.Println(Parse("++42"))
	fmt.Println(Parse("4a2"))
	fmt.Println(Parse("-"))
	fmt.Println(Parse(""))
}

Что тут: полный разбор со всеми проверками. Обрати внимание на
краевые случаи: пустая строка, один только знак, двойной знак.
