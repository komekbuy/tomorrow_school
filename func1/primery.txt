ФУНКЦИЯ — кусок кода, которому дали имя, чтобы не переписывать каждый раз.

    func Line() {
     │    │   │
     │    │   └── скобки: место для входных данных
     │    └────── имя, придумываешь сам
     └─────────── ключевое слово

ОБЪЯВИТЬ ≠ ВЫПОЛНИТЬ. Объявление ничего не делает — это описание.
Чтобы сработало, надо ВЫЗВАТЬ: написать имя со скобками  Line()

ПАРАМЕТР — данные снаружи. Пишутся в скобках: имя и тип.
    func Stars(n int)      объявление, параметр называется n
    Stars(5)               вызов, аргумент 5 попадает в n
Несколько — через запятую, ПОРЯДОК ВАЖЕН: func Repeat(c rune, n int)

ВНУТРИ ФУНКЦИИ пользуешься именем ПАРАМЕТРА, а не каким угодно.
    func Teen(n int) { if i >= 13 ... }   ← ОШИБКА: undefined: i

IF — выбор. Условие снаружи скобок, БЕЗ круглых. Фигурные обязательны.
    if n > 5 {
        действие         ← только если условие истинно
    }
                         ← а здесь выполняется ВСЕГДА

    else пишется НА ТОЙ ЖЕ СТРОКЕ, что закрывающая скобка:
    } else {

СРАВНЕНИЯ:  >  <  >=  <=  ==  !=
    == это сравнение (ДВА знака), = это присваивание. Не путать.

else if — цепочка проверок. Идут СВЕРХУ ВНИЗ, срабатывает ПЕРВАЯ подошедшая.

&& и ||
    &&  «И»    истинно когда истинны ВСЕ части
    ||  «ИЛИ»  истинно когда истинна ХОТЯ БЫ ОДНА

    Одну переменную проверяешь на несколько значений → всегда ||
    (переменная не может быть равна двум значениям сразу)
    Диапазон или разные вещи → &&

    КАЖДОЕ сравнение должно быть ПОЛНЫМ:
       c == 'a' || c == 'e'        ✅
       c == 'a' || 'e'             ❌ вторая часть не сравнение

ГРАБЛИ: сначала было i := 0 и внутренний j < i — при i=0 внутренний цикл
не выполнялся ни разу, первая строка выходила ПУСТОЙ.

ПРИЁМ: до запуска выписать таблицу — какие значения примет i и что получится
на каждом шаге. Ошибки с границами так ловятся сразу.

--- Задача: символы от '0' до 'z'; цифры и строчные буквы печатать как есть,
    остальное заменить на точку ---
    РЕШЕНО. Самое сложное — условие с двумя диапазонами — собрал сам.

package main

import "github.com/01-edu/z01"

func Alphabets(n rune) {
	if (n >= '0' && n <= '9') || (n >= 'a' && n <= 'z') {
		z01.PrintRune(n)
	} else {
		z01.PrintRune('.')
	}
}

func main() {
	for c := '0'; c <= 'z'; c++ {
		Alphabets(c)
	}
	z01.PrintRune('\n')
}

Вывод:
0123456789.......................................abcdefghijklmnopqrstuvwxyz

39 точек между цифрами и буквами — там прячутся заглавные буквы и знаки
препинания (коды 58..96).

ГДЕ && , А ГДЕ ||  — правило:
    ВНУТРИ скобок  &&   диапазон = две границы про ОДНУ переменную,
                        обе должны выполняться вместе
    МЕЖДУ скобками ||   подходит ЛИБО одна группа, ЛИБО другая
                        (символ не может быть цифрой и буквой одновременно)

    if ( граница && граница ) || ( граница && граница )
         └──── группа 1 ────┘      └──── группа 2 ────┘
              «цифра»                  «строчная буква»

ГРАБЛИ (обе повторились дважды за сессию):

 1) ДИАПАЗОН РАЗВЁРНУТ НЕ В ТУ СТОРОНУ
    было:  n <= '0' && n >= '9'    «меньше нуля И больше девятки» — невозможно
    надо:  n >= '0' && n <= '9'    «не меньше нуля И не больше девятки»

           '0'              '9'
       ─────┼────────────────┼─────
         ↑     ↑↑↑↑↑↑↑↑↑         ↑
      меньше   ЭТО НУЖНО      больше

    ЛЕЧЕНИЕ: подставить конкретное значение и прочитать вслух.
    «Пятёрка меньше нуля?» — нет → условие написано неверно.

 2) ОШИБКА НА ЕДИНИЦУ (граница цикла)
    было:  for c := '0'; c < 'z'   → последняя обработанная 'y', z потерялась
    надо:  for c := '0'; c <= 'z'  → z включена

    ЛЕЧЕНИЕ: посмотреть на ПОСЛЕДНИЙ элемент. Должен ли он попасть в вывод?
    Да → условие обязано быть истинным при c == 'z'.

 3) Цикл написан с одним условием, без создания переменной и без шага:
       for n < '0' && n > 'z' {     → undefined: n
    Форма всегда из трёх частей:  for <создать>; <условие>; <шаг> {

 4) Перевод строки стоял ВНУТРИ функции → каждый символ на своей строке.
    Нужен один раз, ПОСЛЕ цикла, в main.
