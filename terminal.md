# Терминал — шпаргалка

Открыть эту шпаргалку: `cat ~/Projects/tomorrow_school/terminal.md`

## Где я и что тут

```
pwd                 показать, в какой папке я сейчас
ls                  что лежит в папке
ls -a               то же + скрытые файлы (.gitignore, .git)
cd <папка>          зайти в папку
cd ..               выйти на уровень выше
cd ~                домой (~ — это /Users/komekbuy)
cd -                вернуться туда, где был до этого
```

## Быстро попасть в нужную папку

```
Tab                 дописывает путь сам: cd ~/Pro + Tab → cd ~/Projects/
cd + перетащить     написать "cd ", перетащить папку из Finder в терминал
ts                  моя команда: cd ~/Projects/tomorrow_school
mini                моя команда: cd ~/Projects/tomorrow_school/sandbox/go-refresh-mini
```

Своя команда (alias) заводится один раз:
`echo "alias имя='cd путь'" >> ~/.zshrc`, потом `source ~/.zshrc`.
`>>` дописывает в конец файла. Один `>` стёр бы весь файл.

## Файлы и папки

```
touch <файл>        создать пустой файл
mkdir <папка>       создать папку
mkdir -p a/b/c      создать сразу цепочку папок
cat <файл>          показать, что внутри файла
cp <откуда> <куда>  скопировать файл
mv <откуда> <куда>  переместить или переименовать
rm <файл>           удалить файл — НАВСЕГДА, без корзины
code <файл>         открыть файл в VS Code
code .              открыть всю текущую папку в VS Code
```

## Go

```
go run .            запустить программу из текущей папки
go run ./папка      запустить программу из другой папки
go test ./...       запустить все тесты
gofmt -l .          показать файлы с неправильным оформлением
go fmt ./...        исправить оформление
go build            собрать программу в один файл
```

## Git

```
git status                  что изменилось
git add <файл>              добавить файл в коммит (только свои файлы, не add .)
git commit -m "сообщение"   сохранить коммит
git push                    отправить на сервер
git log --oneline           список коммитов
```

## Клавиши

```
Tab                 дописать имя файла или папки
↑ / ↓               прошлые команды
Ctrl + C            остановить зависшую программу
Ctrl + L            очистить экран (или команда clear)
```
