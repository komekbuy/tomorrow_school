================================================================================
        НАСТРОЙКИ VS CODE — УБРАТЬ ЛИШНИЕ ПОДСКАЗКИ
                    (для работы с Go)
================================================================================

ЗАЧЕМ: на школьном редакторе, где сдаётся экзамен, подсказок НЕТ.
Тренироваться надо в тех же условиях. Плюс они отвлекают.

--------------------------------------------------------------------------------
КАК ОТКРЫТЬ НАСТРОЙКИ
--------------------------------------------------------------------------------

    Cmd + Shift + P
    набрать:  Preferences: Open User Settings (JSON)
    Enter

Откроется файл settings.json — это обычный текстовый файл с настройками.

--------------------------------------------------------------------------------
ЧТО ВСТАВИТЬ
--------------------------------------------------------------------------------

{
    "go.inlayHints.assignVariableTypes": false,
    "go.inlayHints.compositeLiteralFields": false,
    "go.inlayHints.compositeLiteralTypes": false,
    "go.inlayHints.constantValues": false,
    "go.inlayHints.functionTypeParameters": false,
    "go.inlayHints.parameterNames": false,
    "go.inlayHints.rangeVariableTypes": false,

    "editor.quickSuggestions": false,
    "editor.suggestOnTriggerCharacters": false,
    "editor.parameterHints.enabled": false,
    "editor.hover.delay": 1500
}

ВНИМАНИЕ: если в settings.json уже что-то есть — не стирай, а допиши эти
строки внутрь существующих фигурных скобок, через запятую после последней
строки. Каждая строка кроме последней заканчивается запятой.

--------------------------------------------------------------------------------
ЧТО КАЖДАЯ НАСТРОЙКА ДЕЛАЕТ
--------------------------------------------------------------------------------

go.inlayHints.*                серые подписи типов прямо в коде
                               (name string, i int и т.п. появлялись сами)

editor.quickSuggestions        всплывающий список вариантов при наборе

editor.suggestOnTriggerCharacters
                               список после точки: набрал "z01." → выпадал список

editor.parameterHints.enabled  подсказка аргументов при вводе открывающей скобки

editor.hover.delay: 1500       всплывашка при наведении мышкой.
                               НЕ убрана, а задержана на 1,5 секунды —
                               случайно наводя, уже не выскакивает

--------------------------------------------------------------------------------
ЧТО ОСТАЛОСЬ РАБОТАТЬ
--------------------------------------------------------------------------------

+ КРАСНОЕ ПОДЧЁРКИВАНИЕ ОШИБОК — специально не отключено.
  Компилятор ругается и на экзамене тоже, это надо видеть.

+ АВТОДОПОЛНЕНИЕ по требованию — вызывается вручную:

      Ctrl + Space

  То есть оно никуда не делось, просто перестало лезть само.

--------------------------------------------------------------------------------
КАК ВЕРНУТЬ ОБРАТНО
--------------------------------------------------------------------------------

Вариант 1 — вернуть всё:
    удалить вставленные строки из settings.json и сохранить (Cmd + S)

Вариант 2 — вернуть частично (если стало слишком голо):
    поменять false на true у нужной строки.

    Чаще всего хочется вернуть именно эту:
        "editor.quickSuggestions": true

    Остальное обычно и не нужно.

Вариант 3 — через интерфейс, без JSON:
    Cmd + ,   (запятая)
    в поиске набрать название настройки, например "inlay hints"
    переключить галочку

--------------------------------------------------------------------------------
ЕСЛИ ЧТО-ТО СЛОМАЛОСЬ
--------------------------------------------------------------------------------

settings.json — обычный текстовый файл, испортить необратимо нельзя.
Если VS Code ругается на синтаксис (жёлтая или красная волна в самом
settings.json) — скорее всего:
    - потеряна запятая между строками
    - или лишняя запятая после ПОСЛЕДНЕЙ строки (её быть не должно)
    - или не закрыта фигурная скобка }

Проверь эти три вещи. Формат JSON такой же строгий, как код.
